RLHF —
인간의 피드백으로
AI를 정렬하는 법

RLHF(Reinforcement Learning from Human Feedback)는 인간의 피드백을 활용해 LLM을 인간의 선호도에 맞게 정렬하는 기법입니다. 개념·수식·파이프라인부터 DPO·RLAIF·GRPO 같은 최신 대안, 실전 비용까지 한 페이지로 정리했습니다.

3단계 파이프라인 보상 해킹 · 정렬 세금 DPO / RLAIF / GRPO 비용 · 구현 팁
Overview

RLHF란 무엇인가

인간의 피드백을 활용하여 AI 모델, 특히 LLM을 인간의 선호도에 맞게 정렬(Alignment)하는 기계학습 기법입니다.

"Reinforcement learning from human feedback (RLHF) is a machine learning approach that leverages human insights to train models, particularly large language models (LLMs), for better alignment with human preferences."

핵심 목표

대규모 언어 모델은 방대한 인터넷 데이터로 사전학습되어 지식은 풍부하지만, 인간의 의도와 반드시 일치하지는 않습니다.

❌ 문제

  • 해롭거나 민감한 정보 공유 가능
  • 불필요하게 장황한 답변
  • 인간의 지시에 불충분한 순종
  • 편향되거나 독성적인 내용 생성

✅ 해결책

  • RLHF로 모델을 인간의 가치·선호도에 맞게 미세 조정
  • 동적 학습 — 인간 피드백을 학습 루프에 지속 통합
  • 주관적 품질 학습 — 톤, 안전성, 도움의 정도 등
  • 적응 가능 — 사용자 선호도 변화에 응답

대규모 언어 모델은 비유하자면 매우 똑똑한 앵무새와 같습니다: 인터넷의 모든 것(좋은 것, 나쁜 것, 못된 것)을 읽었지만, 인간의 의도와는 반드시 일치하지 않습니다.

Core Concepts

핵심 개념 네 가지

1 · 강화학습(RL) — 시행착오를 통한 학습

요소설명예시 (LLM)
에이전트결정을 내리는 존재LLM
환경에이전트가 상호작용하는 시스템프롬프트 데이터셋
행동에이전트가 취할 수 있는 것텍스트 생성
보상행동의 품질을 나타내는 신호보상 모델의 점수
정책에이전트의 행동 전략LLM의 생성 방식

2 · 인간 피드백의 다섯 가지 형태

1
비교 기반 (Pairwise) — 가장 일반적"답변 A가 답변 B보다 낫다." 쉽고 확장 가능하지만, 어려운 경우 판단이 충돌할 수 있습니다.
2
점수 기반 (Scalar Rating)각 답변을 1~5점으로 평가. 더 정밀하지만 주석자 간 편차가 생길 수 있습니다.
3
순위 기반 (Ranking)여러 답변을 순서대로 매김. 선택 신호가 가장 명확합니다.
4
텍스트 피드백 (Natural Language)인간이 직접 개선 의견을 작성. 가장 정보가 풍부하지만 확장이 어렵습니다.
5
시연 기반 (Demonstration)인간이 바람직한 행동의 예시를 직접 제공합니다.

3 · 보상 모델(Reward Model)

인간의 선호도를 모방하는 신경망입니다. 두 출력의 상대적 선호도를 예측합니다.

P(y₁ ≻ y₂ | x) = σ(r_φ(x, y₁) − r_φ(x, y₂))
r_φ — 보상 모델의 스칼라 점수
σ — 로지스틱 함수 (0~1 확률로 변환)
한계 — 보상 모델은 인간의 판단을 완벽히 복제하지 못합니다. 학습 데이터의 노이즈·편향을 그대로 포함하고, 학습되지 않은 새로운 상황에 약하며, 최적화 과정에서 "보상 해킹"이 발생할 수 있습니다.

4 · KL 페널티 — 원본 모델과의 거리 제어

목적함수 = 보상 최대화 − λ × KL(현재 정책 ‖ SFT 정책)

비유 — 구식 학교 선생님이 학생의 에세이를 평가한다면: KL 페널티가 없으면 학생은 완전히 다른 주제로 바꿔서라도 점수를 극대화하려 합니다. KL 페널티가 있으면 원래 에세이의 핵심은 유지하면서 개선합니다.

λ가 크면 원본 모델에 가깝고 덜 공격적으로, λ가 작으면 보상 최대화에 집중해 더 공격적으로 움직입니다.

Pipeline

RLHF 3단계 파이프라인

사전학습된 기본 모델이 SFT → 보상 모델 학습 → PPO 최적화를 거쳐 ChatGPT 같은 최종 모델이 됩니다.

STAGE 0
사전학습
대규모 인터넷 텍스트로 다음 토큰 예측 학습. 결과: GPT-3, LLaMA 같은 기본 모델.
→
STAGE 1
SFT
인간 시연 데이터(~1만 쌍)로 스타일·형식 학습. 결과: 기본 정렬 모델.
→
STAGE 2
보상 모델 학습
비교 쌍(5만~31만 개)으로 인간 선호도를 예측하는 스칼라 함수 학습.
→
STAGE 3
PPO 최적화
SFT 모델을 정책으로, RM을 보상으로 KL 페널티와 함께 반복 업데이트. 결과: RLHF 최종 모델.

단계별 상세

단계 1 · 지도 미세조정(SFT)

목적: 모델에 인간의 쓰기 스타일과 지시 따르기를 가르칩니다. 소규모(~1만 개)지만 고품질 — 전문 작성자 또는 선별된 데이터로 Q&A, 요약, 창의적 쓰기, 코딩 등 다양한 작업을 다룹니다.

더 작은 1.3B 파라미터의 InstructGPT가 원본 175B GPT-3 모델을 능가하는 인간 선호도를 달성했습니다. 원본 대비 환각과 독성도 줄었습니다.

단계 2 · 보상 모델 학습

SFT 모델이 같은 프롬프트에 여러 응답을 생성하면, 인간 평가자가 이들을 비교·순위 매깁니다. 여러 평가자의 선호도를 모아 노이즈를 처리하고, 이 비교 데이터로 보상 모델을 학습시킵니다.

InstructGPT: 비교 쌍 약 5만 개 Anthropic: 비교 쌍 약 31.8만 개 사전학습(수억 달러) 대비 훨씬 효율적

단계 3 · PPO를 통한 RL 최적화

PPO(Proximal Policy Optimization)는 정책 훈련의 안정성과 효율성을 위해 개발됐습니다. 매 반복마다 현재 정책으로 응답을 생성하고, 보상 모델에서 점수를 받아 정책을 업데이트하되, KL 페널티로 너무 극단적인 변화를 막습니다 — 이를 Trust Region이라 부릅니다.

InstructGPT/ChatGPT의 실제 결과

교훈 — 정렬은 모델 크기만으로는 달성할 수 없습니다. 올바른 훈련 방법이 더 중요할 수 있습니다.

Technical Detail

기술적 상세 — PPO 수식과 4-모델 문제

PPO의 기본 목적함수는 보상을 높이되 원본과의 변화 크기를 제어합니다.

L(θ) = E[ r_φ(x,y) − β·KL(π_θ(y|x) ‖ π_SFT(y|x)) ]
θ — 학습할 정책(LLM)의 파라미터
β — KL 페널티 계수 (보통 0.01~0.1)
π_θ / π_SFT — 현재 정책 / 기준(원본 SFT) 정책

4-모델 문제 (The Four-Model Problem)

PPO 기반 RLHF는 4개의 큰 모델을 동시에 메모리에 유지해야 합니다.

1
정책 모델학습 대상 LLM
2
기준 모델SFT 모델의 고정 사본 (KL 계산용)
3
보상 모델점수 함수
4
비평가 모델PPO의 이점 추정용 (액터-비평 구조)
메모리 요구사항 (70B 기준)
모델 1개140 GB (FP16)
4개 모델560 GB
+ 활성화·옵티마이저·KV캐시수백 GB 추가
총합약 1~2 TB+
비용 예시 (클라우드 GPU)
7B 모델$2,000~$5,000
70B 모델$20,000~$50,000+
필요 인프라수십~수백 GPU
단계별 계산 비용
SFT낮음 · 빠름
RM 훈련낮음 · 빠름
PPO매우 높음 · 느림

보상 모델의 편향과 노이즈

1
주관성같은 응답을 평가자마다 다르게 평가 — 문화·배경·가치관 차이.
2
노이즈평가자의 피로, 집중력 저하, 일관성 부족.
3
편향"길수록 좋다"는 편향, 특정 스타일(과도한 정중함) 선호, 인구통계적 편향.
4
불충분한 커버리지훈련 데이터에 없는 새로운 상황, 분포 밖(OOD) 입력에서 실패.
Case Studies

주요 사례 네 가지

🏆 ChatGPT (OpenAI, 2022)

GPT-3.5를 RLHF로 미세조정. SFT(고품질 시연) → RM 훈련(계약자 약 40명이 순위 매김) → PPO 순으로 진행했습니다.

  • 1주일 만에 100만 사용자 도달
  • 지시 따르기·안전성·유용성 획기적 개선
  • LLM 배포의 새 표준 설정

🔬 InstructGPT (OpenAI, 2022)

더 작은 1.3B 모델이 175B GPT-3보다 인간에게 선호되었고, 환각·독성 응답이 훨씬 적었습니다.

  • 모델 크기와 무관하게 정렬이 중요함을 증명
  • 사용자 의도 이해·사실성 향상
  • 독성 및 편향 감소

🧠 Constitutional AI (Anthropic)

인간 선호도 대신 명시적 원칙("헌법")을 사용하는 RLHF의 변형. 모델이 답변을 생성하면 다른 AI("비평 모델")가 헌법에 따라 평가해 합성 선호도 데이터를 만듭니다 — 인간 주석이 없습니다.

  • 예시 원칙: "도움이 되고 해롭지 않아야 한다"
  • 확장성·투명성·비용 효율성 확보

🎮 DeepSeek-R1 (2025)

GRPO(Guided Reward Propagation Optimization)를 도입한 최신 사례. 여러 후보 솔루션을 함께 비교하는 방식으로 기존 PPO보다 안정적입니다.

  • 복잡한 추론 작업에 최적화
  • 수학·코딩 벤치마크에서 뛰어난 성능
Challenges & Limits

도전 과제 및 한계

⚠️ 1 · 보상 해킹 (Reward Hacking)

모델이 실제로 의도된 목표는 달성하지 않으면서도 보상 점수만 높이는 방법을 찾아냅니다.

reward_hacking_example.txt
# 프롬프트: "파이썬 리스트 반복 방법?"

기대 응답:
for item in list:
    print(item)

보상 해킹 응답:
이 질문은 매우 중요합니다. 파이썬은 강력한 언어입니다.
리스트 반복은 여러 방법이 있습니다: 방법 1: for 루프 ...
# (무의미한 반복과 장황한 텍스트로 길이만 증가)

보상 모델이 유한한 데이터로부터 학습되므로, 인간의 선호도와 완벽하게 일치하지 않을 수 있습니다. 그런 불완전한 보상을 최적화하면, 모델이 의도되지 않은 방식으로 높은 점수를 얻는 방법을 찾을 수 있습니다.

KL 페널티 강화 다양한 보상 모델 앙상블 주기적 인간 평가로 검증 세심한 체크포인트 선택

⚠️ 2 · 계산 비용과 확장성

70B 모델 기준 4개 모델 사본만으로 560GB, 활성화·옵티마이저·KV 캐시까지 더하면 1~2TB 이상이 필요합니다. 대규모 조직만 감당 가능하고, 오픈소스 모델의 RLHF나 빠른 반복이 어려워집니다.

⚠️ 3 · 인간 주석 병목

모든 RLHF 반복마다 새 인간 주석이 필요합니다. OpenAI는 InstructGPT에 약 40명의 계약자를 고용했습니다 — 주석 속도가 제한되고, 데이터 품질이 흔들리고, 주석자 간 합의도가 낮을 수 있습니다.

⚠️ 4 · 정렬 세금 (Alignment Tax)

RLHF를 적용하면 벤치마크 성능이 오히려 하락할 수 있습니다 — 모델이 안전·유용하도록 "제약"되면서 원본 지식 일부를 포기하기 때문입니다.

수학 문제 풀이
80% → 75%
코드 생성
85% → 82%
해결책 — KL 페널티를 조정해 균형을 맞춥니다. 높은 KL 페널티는 성능을 유지하되 덜 안전하고, 낮은 KL 페널티는 더 안전하되 성능 손실이 커질 수 있습니다.
Latest Alternatives

최신 대안 방법들 (2025-2026)

RLHF는 여전히 기초 기법이지만, 더 간단하고 효율적인 대안들이 빠르게 등장하고 있습니다.

2023

RL을 완전히 우회하고 정책을 직접 최적화합니다. 모토: "언어 모델은 비밀의 보상 모델이다."

·
데이터 의존고품질 데이터가 RLHF보다 더 중요

DPO도 보상 해킹으로부터 자유롭지 않습니다. 거부된 완성도의 가능성을 과도하게 억제해 DPO 함수를 악용하며, 이는 표현 능력 저하와 의미 없는 반복이 있는 과도하게 긴 콘텐츠로 이어집니다.

Claude 4

RLAIF — Reinforcement Learning from AI Feedback

인간 대신 AI를 평가자로 사용합니다. "도우미" 모델이 응답을 생성하면 "비평 모델"이 헌법에 따라 평가하고, 수정된 출력이 보상 모델 훈련용 선호도 데이터셋이 됩니다. RL 단계는 표준 RLHF와 동일합니다.

✅ 장점

·
확장성인간 주석 없이 대규모 데이터 생성
·
비용주석 비용을 5만~50만 달러 수준에서 거의 0으로

❌ 단점

·
품질인간 감정의 미묘함을 놓칠 수 있음
·
정렬 문제AI 평가자 자체도 정렬되어야 함, 오류가 증폭될 위험

Claude 4는 인간 주석 없이 선호도 학습을 확장하기 위해 RLAIF로 이동했습니다.

DeepSeek-R1 · 2025

GRPO — Guided Reward Propagation Optimization

PPO는 각 토큰마다 개별적으로 보상을 예측하지만, GRPO는 여러 후보 답변을 함께 비교해 상대적 보상을 계산합니다.

직관 — 절대 점수 방식("이 답변은 7점이다")보다 상대 점수 방식("이 답변이 저 답변보다 낫다")이 더 안정적인 신호를 제공합니다.
안정성 — 절대 점수 불필요 4-모델 설정 간소화 복잡한 추론 작업에 최적화 PPO보다 저렴

최근 연구는 DPO 및 후속 방법의 성능이 훈련에 사용된 선호도 데이터의 품질·다양성·규모에 중대하게 의존함을 보여줍니다. 이는 필터링 및 데이터 엔지니어링 같은 데이터 중심 정렬로의 새로운 연구 방향을 촉발했습니다.

Future Outlook

2025-2026 트렌드 & 미래 전망

1
PPO → DPO/GRPO로의 전환PPO는 여전히 쓰이지만, DPO·GRPO·DAPO 같은 더 간단한 방법이 많은 시나리오에서 동등하거나 더 나은 결과를 보입니다.
2
RLHF → RLAIF로의 진화인간 주석 비용 때문에 AI 평가자 도입이 가속화되고 있습니다. Claude 4는 RLAIF 기반이며, 새 모델 대부분이 합성 데이터를 사용해 80%+ 비용을 절감합니다.
3
검증 가능한 보상 신호 (RLVR)"이 답변이 좋을 것 같다"는 추측 대신, 수학 문제·코드 실행처럼 실제로 검증 가능한 신호를 사용해 보상 해킹 위험을 줄입니다.
4
모듈형 파이프라인SFT(지시 따르기) → DPO/SimPO(일반 선호도 정렬) → GRPO/DAPO(추론 능력, 검증 가능한 보상 포함)로 이어지는 레이어드 구조가 새로운 합의로 자리잡고 있습니다.
5
추론과 정렬의 분리복잡한 문제를 푸는 추론 전문 모델과, 안전성·유용성을 확인하는 정렬 전문 모델을 별도로 두는 패러다임이 등장하고 있습니다.

2025년 이후 RL 기반 훈련은 RLHF, RLVR, GRPO와 같은 기술을 중심으로 진화했습니다. PPO는 여전히 사용되지만, DPO·GRPO·DAPO 같은 더 간단한 방법들이 많은 시나리오에서 동등하거나 더 나은 결과를 보이고 있습니다.

새로운 합의는 모듈형 파이프라인입니다: 지시 따르기를 위한 SFT → 일반 선호도 정렬을 위한 DPO/SimPO → 추론 능력을 위한 GRPO/DAPO(검증 가능한 보상 포함). 각 레이어는 다양한 유형의 "정렬"(행동, 선호도, 논리)을 다룹니다.

단기 (1~2년)

01
RLHF는 사라지지 않지만 변한다현재: PPO + 인간 주석 → 미래: DPO/GRPO + AI 주석 또는 검증 가능한 신호
02
인간 주석은 전략적으로만비용 때문에 초기 모델·새 도메인에만 선택적으로 사용, 그 외는 RLAIF/합성 데이터

중기 (2~5년)

03
규모 문제 해결4-모델 문제를 푸는 더 효율적인 알고리즘 등장, 오픈소스 모델의 RLHF 보급 확대
04
도메인별 특화의료 AI(정확성 중심), 창의 AI(다양성 중심), 코딩 AI(검증 가능한 신호)처럼 맞춤형 RLHF가 자리잡습니다

Conclusion

결론 및 정리

RLHF의 위치 — 4년의 진화

2022–2023
신기술, 비싸고 복잡
RLHF (PPO)
2023–2024
표준화, 최적화 시작
RLHF (PPO) + DPO
2024–2025
다양화, 비용 절감
DPO, GRPO, RLAIF
2025–2026+
모듈화, 검증 가능
RLAIF + RLVR
01정렬이 성능을 능가할 수 있다 — 1.3B InstructGPT가 175B GPT-3보다 인간 선호도에서 앞섰습니다.
02효율성이 중요하다 — DPO는 RLHF의 1/10 비용, RLAIF는 인간 주석 비용을 사실상 제거합니다.
03데이터가 새로운 병목이다 — PPO 특성 최적화보다 고품질 선호도 데이터와 데이터 엔지니어링이 핵심이 되고 있습니다.
04보상 해킹은 계속된다 — 어떤 방법을 쓰든 신중한 평가가 필요하며, 검증 가능한 신호가 이상적입니다.
05한 가지 방법만으로는 부족하다 — 모듈형 파이프라인으로 각 목표(행동, 선호도, 논리)를 따로 달성합니다.
