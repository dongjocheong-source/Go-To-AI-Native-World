프롬프트 엔지니어링이란 무엇인가
개념 · 배경 · LLM 핵심 파라미터

프롬프트 엔지니어링은 '좋은 질문'을 던지는 게 아니라, AI로부터 가장 정확하고 유용한 응답을 이끌어내는 지시문을 설계·테스트·개선하는 과정입니다. 이 편에서는 개념과 역사, 그리고 AI의 '성격'을 조절하는 핵심 파라미터를 정리합니다.

Concept

개념 정의 — '질문'이 아닌 '설계'

AI 모델(LLM)로부터 가장 정확하고, 관련성 높고, 유용한 응답을 이끌어내기 위해 효과적인 지시문(프롬프트)을 설계하고, 테스트하고, 개선하는 모든 과정을 의미합니다.

단순히 '좋은 질문'을 던지는 게 아닙니다. AI가 주어진 텍스트(토큰)를 기반으로 다음 토큰을 예측하는 방식으로 작동한다는 것을 이해하고, '인간의 의도'와 '기계의 이해' 사이의 다리를 놓는 '설계' 작업입니다.

Why It Matters

현업에서의 중요성 — 왜 "엔지니어링"인가

'고객 지원 챗봇' 예시로 바로 알아보겠습니다.

❌ 엔지니어링 없이

  • 챗봇이 "무엇을 도와드릴까요?"만 반복
  • "배송 언제 와요?" → "이해하지 못했습니다"

✅ 엔지니어링 적용

  • "주문 번호를 'XXXX-XXXX' 형식으로 입력해 주세요"처럼 명확히 유도
  • 특정 형식 입력을 받고, 불만에 공감하며, 복잡한 문제는 인간 상담사에게 이관하도록 설계
원하는 결과를 '안정적으로' 제어하고 예측 가능하게 만드는 모든 과정이 바로 '엔지니어링' 영역입니다.
LLM Parameters

창의성 · 샘플링 제어

AI가 다음 단어를 '선택'하는 방식을 제어하는 파라미터들입니다.

T
Temperature (창의성)모델의 무작위성 조절 (0.0~2.0+). 낮으면(0.1) 정해진 답변(사실 기반 QA, 코드 생성), 높으면(0.9) 창의적이지만 엉뚱할 수 있는 답변(소설, 브레인스토밍).
P
Top_p (신중함)확률이 높은 단어 중 '상위 %'까지만 후보로 둠 (0.0~1.0). top_p=0.2면 상위 20% 확률의 단어들 내에서만 선택 — Temperature보다 보수적입니다.
K
Top_k (선택지 개수)확률과 무관하게 '상위 K개'의 단어만 후보로 둠. top_k=50이면 가장 유력한 50개 단어 중에서만 고릅니다.
·
Typical_p / Min_p (고급)Typical_p는 '평범한' 확률의 단어를, Min_p는 '최소' 확률 이상의 단어만 샘플링하는 좀 더 복잡한 방식입니다.
꿀팁 🍯 Temperature와 Top_p는 결정성을 제어한다는 점에서 비슷합니다 — 둘 중 하나만 조절하는 것이 좋습니다. 둘 다 건드리면 결과 예측이 더 복잡해집니다.
LLM Parameters

반복 억제 (Penalty)

AI가 '고장 난 것처럼' 같은 말을 되풀이하는 것을 방지합니다.

F
Frequency Penalty이미 사용한 '단어'의 재등장 확률을 낮춥니다. "AI는... AI는... AI는..." 같은 기계적 반복을 방지합니다.
P
Presence Penalty이미 언급한 '주제'의 재등장 확률을 낮춥니다. 비슷한 주제가 반복되는 것을 방지하고 새 주제 탐색을 유도합니다.
R
Repetition Penalty위 두 방식과 유사하게, 이전 토큰들을 기반으로 반복에 대한 페널티를 종합적으로 적용합니다.
LLM Parameters

출력 제어

결과물의 형식과 길이를 '물리적으로' 제어합니다.

M
Max / Min Tokens생성할 최대·최소 토큰 수를 제한합니다. 비용 관리와 응답 시간 제어에 필수적입니다.
S
Stop Sequences특정 문자열(예: \n, ###)을 생성하면 즉시 중단시킵니다. 원하는 형식의 답변만 깔끔하게 받아내는 '형식 제어'의 핵심입니다.
J
JSON ModeAI가 절대 깨지지 않는 유효한(Valid) JSON 형식의 텍스트만 출력하도록 보장하는 '미친' 편의 기능입니다.
LLM Parameters

행동 · 토큰 제어

모델의 근본적인 행동 방식을 제어합니다.

S
Seed (결과 고정)난수 생성 시드를 고정. seed=123처럼 값을 고정하면 Temperature가 높아도 항상 동일한 결과가 나옵니다 — 테스트·디버깅의 "국룰".
L
Logit Bias특정 토큰의 선택 확률을 인위적으로 조작. 예: {"엔비디아": 10, "AMD": -10} → 특정 단어를 더 자주/절대 말하지 않게 유도.
SYS
System Prompt (AI 페르소나)AI에게 '역할'을 부여하는 가장 중요한 지시문. "너는 10년 차 파이썬 개발자이며, 항상 코드 예시를 포함해 답변해야 해."처럼 근본적 정체성을 설정합니다.
