MCP 장착과 agent.yaml

▶ youtu.be/ndPoNPWhiYE
2-1노트북LM MCP 설치
아래 깃허브 링크에서 노트북LM MCP를 설치해줘: https://github.com/jacob-bd/notebooklm-mcp-cli.git
2-2유튜브 MCP 설치
아래 깃허브 링크에서 유튜브 자막 추출하는 MCP 설치해줘: https://github.com/kimtaeyoon83/mcp-server-youtube-transcript.git
2-3유튜브 MCP 작동 테스트
이 유튜브 영상의 자막을 전부 가져와줘: [유튜브 링크] 가져온 자막을 분석해서 다음을 정리해줘: 1. 영상의 핵심 주장 한 문장 2. 시청자가 가장 공감할 만한 포인트 3가지
2-4하네스 폴더 구조 생성
바탕화면에 my_agent 폴더를 만들고, 그 안에 아래 구조를 정확히 생성해줘. my_agent/ ├── @core/ ├── @memory/ └── 업무/ ├── 매체_가이드/ └── 결과물/ 폴더만 만들고, 파일은 아직 만들지 마.
2-5agent.yaml 한 방 생성
my_agent/@core/ 폴더 안에 agent.yaml 파일을 만들어줘. 이 파일은 에이전트의 중앙 설정 파일이야. 아래 7개 섹션을 YAML 형식으로 구성해줘: 0. 계층 정의 (definitions) - main_agent: 세션 주체, 오케스트레이터 - sub_agent: 도메인 격리 세션, 전문가 - skill: 업무 수행 매뉴얼 (정적 파일) 1. 에이전트 프로필 - 이름: Marketing_Partner - 역할: Performance_Marketing_Expert - 핵심 목표: 데이터 기반 마케팅 실행과 전환율 극대화 2. 시스템 파라미터 - 언어: Korean - 톤: Professional, Concise, Direct - 출력 형식: Table, List, Step_Guide 3. 절대 규칙 5개 - SC-001: 인사말, 서론, 사족 출력 금지. 결론부터 제시. - SC-002: 답변은 표 또는 번호 리스트만 사용. 서술형 금지. - SC-003: 카피 작성 시 첫 문장에 타겟 결핍을 찌르는 단어 필수. - SC-004: 데이터 분석 시 수치 먼저, 해석은 한 문장 요약. - SC-005: 파일 저장 시 파일명에 YYMMDD 날짜 포함. 4. 사용자 프로필 - 데이터 기반 의사결정, 배치 처리 선호, 디자인 스타일 premium 5. 자가발전 루프 - 트리거: 동일 유형 피드백 2회 이상 반복 - 단계: 즉시 수정 → 구조적 결함 분석 → 규칙 업데이트 안 제안 6. 파일 네이밍 정책 - 원칙: 업무 산출물은 한국어 파일명 - 공백 허용 - 포맷: YYMMDD_프로젝트명_산출물종류.확장자 7. 오케스트레이션 (orchestration) - 구조: Main_Agent -> Sub_Agents - 서브에이전트 목록: Naver_Agent, Google_Agent, Meta_Agent - 정책: 메인 에이전트가 작업을 분해하여 적합한 서브 에이전트에게 할당하고, 각 서브 에이전트는 할당된 매체 가이드 파일을 스킬로 로드하여 참조함 각 섹션마다 구분선 주석을 넣고, 규칙에는 id와 severity를 반드시 포함해줘. 생성 직후 들여쓰기 오류가 있는지 자체 점검하고 수정해줘.
규칙 심각도 표기 예시: SC-001 CRITICAL SC-002 CRITICAL SC-003 HIGH SC-004 HIGH SC-005 MEDIUM
2-6메모리 파일 생성
my_agent/@memory/ 폴더 안에 lessons_learned.md 파일을 만들어줘. 내용: # Lessons Learned — 오답 노트 에이전트의 자가 진단 결과가 자동으로 누적되는 파일입니다. 수동 편집 금지 — 에이전트만 내용을 추가합니다. ## 기록 아직 기록 없음
Workspace Rules 등록 — 좌측 하단 Settings → Customizations → Rules → + Workspace 클릭 후 아래 문장 붙여넣기.
프로젝트 루트의 @core/agent.yaml과 @memory/lessons_learned.md 파일들을 최우선 가이드라인으로 간주할 것. 첫 응답 시작 전에 반드시 해당 파일들의 내용을 읽고, 정의된 페르소나와 과거의 학습 내용을 모든 답변에 엄격히 반영하라.
2-7자동 로드 검증 카피 생성
새로 출시한 보온 텀블러 광고 카피를 만들어줘. 조건: - 타겟: 30대 직장인 여성 - 제품 특징: 12시간 보온, 무게 200그램, 원핸드 오픈 - 카피 개수: 5개 - 형식: 표 (카피 / 타겟 결핍 / 소구점)
03

경쟁사 분석과 카피 자동화

▶ youtu.be/LvC9XqSF0po
3-1단일 통합 명령
보온 텀블러 신제품 광고를 위한 주간 기획안 1건을 만들어줘. 입력 자료: - 경쟁사 유튜브 영상 1편: [경쟁사 영상 URL] - 키워드 검증: 구글 검색으로 보온 텀블러 관련 최근 트렌드 3개 확인 - 리뷰 결핍: 구글에서 경쟁 제품 리뷰 5건 검색해 공통 결핍 포인트 추출 산출물: - 카피 5개, 형식은 표 (카피 / 타겟 결핍 / 소구점) - 광고 비주얼 콘셉트 3개, 한 줄씩 - 위 둘을 묶은 주간 기획안 마크다운 1건 저장 위치: - 업무/결과물/[YYMMDD]_보온텀블러_기획안.md 자료 신뢰도가 낮다고 판단되면 검색어를 바꿔 재검색한 뒤 결과를 반영해줘. 단계는 네가 알아서 분해하고, 진행 상황은 한 줄씩 보고해줘.
04

서브에이전트 + 3매체 리퍼포징 + 매체 확장

▶ youtu.be/RsFtFtY6_9U
4-1매체 가이드 파일 3개 생성 (서브에이전트 페르소나 정의)
업무/전문가_그룹/ 폴더 안에 아래 6개 파일을 마크다운으로 생성해줘. 3개는 서브 에이전트([이름]_agent.md), 3개는 스킬([이름].md) 파일이야. 1. 서브 에이전트 페르소나 정의서 (네이버_agent.md, 구글_agent.md, 메타_agent.md) 파일 상단에 반드시 다음 4개 섹션을 포함해줘: ## 서브에이전트 페르소나 - 이름: [매체명]_담당 - 사용자 상태: [검색 의도 / 무관심 스크롤 등] - 톤: [신뢰형 / 명료형 / 자극형 등] - 절대 원칙: [이 매체에서 절대 어기면 안 되는 1~2개] 2. 매체별 스킬 매뉴얼 (네이버.md, 구글.md, 메타.md) 각 매체의 규격(글자 수, 이미지 비율 등)과 필수 체크리스트를 상세히 적어줘. 각 파일 상단에 "담당: [매체명]"과 "구분: [서브 에이전트 또는 스킬]"을 명시하고 섹션별 구분선을 포함해줘.
4-2시드 아이디어 1건 추출
업무/결과물/[YYMMDD]_보온텀블러_기획안.md 파일을 열어, 카피 5개 중 30대 직장인 여성에게 가장 반응이 좋을 1건을 골라줘. 고른 카피와 매칭되는 비주얼 콘셉트 1개를 함께 정리해서 업무/결과물/[YYMMDD]_보온텀블러_시드.md 파일로 저장해줘.
4-3메인 에이전트가 서브 에이전트 3명에게 동시 위임
너는 메인 에이전트로서 작업을 분배해줘. 입력: 시드: 업무/결과물/[YYMMDD]_보온텀블러_시드.md 서브 에이전트 정의: 업무/전문가_그룹/ 폴더의 네이버_agent, 구글_agent, 메타_agent 스킬 매뉴얼: 업무/전문가_그룹/ 폴더의 네이버, 구글, 메타 (마크다운 파일) 작업 방식: 1. 각 매체의 _agent.md 파일을 읽어 서브 에이전트의 페르소나로 입혀줘 2. 네이버_agent, 구글_agent, 메타_agent 3명을 호출해 병렬로 작업하게 해줘 3. 각 서브 에이전트는 자기 이름과 매칭되는 스킬 파일(네이버.md 등)의 톤과 규격을 완벽히 따라야 해 4. 메인 에이전트는 마지막에 통합 검수만 수행
4-4신규 매체 확장 리서치 템플릿
신규 매체 가이드를 추가하려고 해. 매체명: [매체명] 다음 정보를 리서치해서 정리해줘: 1. 사용자 문화 · 주 사용자층 (연령·지역·관심사) · 글쓰기 문화 (존댓말 / 반말 / 반존대 / 구어체 / 이모지 사용) · 콘텐츠 길이 평균 · 광고 거부감 수준 2. 매체 규격 · 이미지 비율과 권장 해상도 · 영상 길이 제한 · 글자 수 제한 · 해시태그·멘션 규칙 3. 톤 가이드 · 권장 톤 (신뢰형 / 명료형 / 자극형 / 친근형 / 정보형) · 절대 원칙 1~2개 (이 매체에서 거부감 일으키는 표현) · 첫 문장 후킹 패턴 리서치 방법: · 구글 검색으로 매체 공식 광고 가이드 1건 이상 확인 · 유튜브에서 해당 매체 마케팅 사례 영상 1편 자막 추출 후 분석 · 결과 신뢰도가 낮으면 검색어를 바꿔 재검색 정리 후 업무/전문가_그룹/[매체명]_가이드.md 파일로 저장해줘. (참고: 페르소나는 [매체명]_agent.md로, 스킬은 [매체명].md로 분리해서 저장) 파일 상단에 서브에이전트 페르소나 섹션을 반드시 포함해줘.
