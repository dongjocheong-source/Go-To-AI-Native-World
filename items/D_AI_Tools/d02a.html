Before You Start

NotebookLM, 한 줄로 말하면

내가 추가한 자료(소스)를 기반으로만 답변하는 AI입니다. 일반 AI에게 "우리 회사 연차 규정이 어떻게 돼?"라고 물으면 규정을 매번 다시 알려줘야 하지만, NotebookLM은 사내 규정집이나 업무 매뉴얼을 소스 영역에 한 번만 올려두면 이후로는 관련 내용을 찾아 출처와 함께 답해줍니다.

지원하는 소스 & 용량

  • PDF, 워드, 유튜브, 웹사이트, 음성 회의록, 영상 파일까지 지원
  • 여러 폴더에 흩어진 자료를 한 곳에 모아 관리할 때 특히 유용
  • 무료 버전도 노트북 하나당 최대 50개 소스 등록 가능
  • 사진 몇 장만 드래그해도 AI가 내용을 인식하고 요약까지 작성

이런 분께 추천합니다

  • 보고서 · 슬라이드 자료를 자주 만드는 직장인
  • 리서치와 자료 정리에 시간을 많이 쓰는 사람
  • 여러 소스에 흩어진 자료를 정리 없이 방치 중인 사람
  • 무료로 쓸 수 있는 실전 AI 툴을 찾는 입문자
01
Quick Access

구글 앱 런처에 NotebookLM 바로가기 고정하기

구글 우측 상단의 와플 아이콘(앱 런처)에 NotebookLM 아이콘이 새로 추가됐습니다. 자주 쓴다면 아예 맨 위로 고정해두는 게 편합니다.

와플 아이콘 클릭→ 편집 아이콘 클릭→ NotebookLM 드래그해서 위로 이동→ 완료 클릭
덤 팁 — 노트북 목록이 많아지면 기본 카드 보기보다 화면 오른쪽 위에서 목록 보기로 바꾸는 편이 관리하기 훨씬 편합니다.
02
Smarter Sources

Gemini 최신 모델 탑재 — 이미지 이해력 & 내장 리서치

이번 업데이트로 Gemini 최신 모델이 적용되면서 소스를 이해하는 능력이 크게 좋아졌습니다. 그리고 소스가 하나도 없는 상태에서도 구글 검색으로 자료를 찾아주는 리서치 기능이 새로 생겼습니다.

1
이미지도 알아서 요약사진 몇 장만 소스로 드래그해도 각 사진의 내용을 인식하고 요약 글까지 자동으로 작성합니다. 소스를 클릭하면 사진 속 상황을 텍스트로 이해하고 있는 것도 확인할 수 있습니다.
2
Fast Research / Deep Research왼쪽 소스 추가 아래의 검색창에 주제를 입력하면, 가진 자료가 없어도 구글 검색으로 관련 소스를 찾아줍니다. 기본은 Fast Research, 더 깊은 검색이 필요하면 Deep Research를 씁니다. Deep Research는 무료 기준 월 5회까지 사용 가능하며, 실행 시간이 더 오래 걸립니다.
Deep Research 사용 흐름
  1. 검색창에 원하는 주제를 입력 (예: "2026년 교육 유튜브 채널 성장 전략")
  2. AI가 구글 검색으로 관련 소스를 자동 탐색
  3. 가져오기 버튼 클릭 → 소스가 한 번에 등록되고 요약까지 자동 생성
참고 — 검색 도중 인터넷에서 데이터를 못 받아와 오류가 나는 소스가 생기면, 소스 옆 점점점(⋯) 버튼 → 소스 삭제로 바로 지울 수 있습니다.
03
Auto Organize

라벨(Label) — 흩어진 소스를 클릭 한 번에 정리

소스가 많아질수록 관리가 번거로워지는 문제를 라벨 기능이 해결합니다. 왼쪽 위 라벨 아이콘을 클릭하면, 쌓여있던 소스가 주제별로 자동 정리됩니다.

1
폴더가 아니라 라벨일반 폴더처럼 자료를 한 곳에만 나누는 방식이 아닙니다. 하나의 소스에 여러 개의 라벨을 동시에 지정할 수 있습니다 — 예: "교육 산업 콘텐츠"와 "유튜브 트렌드 및 알고리즘"을 한 소스에 동시에 태깅.
2
슬라이드 제작과 바로 연결스튜디오에서 슬라이드를 만들 때 특정 라벨만 선택해서, 전체 소스가 아니라 그 주제에 특화된 자료로만 결과물을 만들 수 있습니다.
3
라벨 직접 추가·이동라벨 아이콘 → 새 라벨 추가로 원하는 이름의 라벨을 만들 수 있고, 기존 소스를 다른 라벨로 옮기는 것도 가능합니다.
소스 옆 더보기(⋯)→ 라벨 지정→ 라벨 아이콘 클릭 시 전체 목록 ↔ 라벨별 보기 전환
04
Custom Persona

맞춤형 대화 스타일 — AI를 30년지기 친구로

업무용으로는 존댓말이 편하지만, 아이디어를 구하거나 일상적인 이야기를 나눌 땐 친구처럼 편하게 반말로 얘기하는 게 더 자연스러울 때가 있습니다. AI도 오랜 친구처럼 솔직하게 말하도록 설정하면 대화가 훨씬 재미있어집니다.

오른쪽 상단 설정 아이콘→ 대화 스타일 · 맞춤 선택→ 페르소나 지시문 입력→ 저장
지시문 예시
  1. "너는 나랑 30년 된 베프다."
  2. "편하게 반말로, 친구처럼 솔직하게 얘기해라."
실제로 써보니 — 무조건 좋은 말만 해주는 게 아니라, 놓쳤던 부분까지 객관적으로 짚어주기 때문에 생각을 정리하거나 중요한 결정을 내릴 때 오히려 더 유용했습니다. 채팅 설정에서 답변 길이도 조절할 수 있는데, 더 깊이 있는 분석이 필요할 땐 길게 옵션을 추천합니다.
05
Infinite Loop

메모 → 소스 변환 — 대화가 다시 지식이 되는 루프

소스를 기반으로 대화를 나누며 지식을 넓히는 것도 좋지만, 그 대화 중 마음에 드는 답변을 다시 소스로 되돌려 넣을 수 있다는 게 NotebookLM의 진짜 강점입니다. 이렇게 하면 지식을 무한히 확장해나갈 수 있습니다.

변환 흐름
  1. 마음에 드는 AI 답변을 확인
  2. 왼쪽 아래 메모 저장 버튼 클릭 → 대화가 메모로 저장됨
  3. 메모의 옵션 → 소스로 변환 클릭 → 답변이 새로운 소스로 추가됨
  4. 라벨 아이콘 → 재고성에서 라벨 없는 소스만 다시 라벨링 실행
결과 — 방금 나눈 대화가 자동으로 적절한 라벨(예: "유튜브 수익화 및 커뮤니티")로 분류되며 정리됩니다.
06
Studio

커스텀 슬라이드 제작 — 스타일만 50가지

오른쪽 스튜디오에서는 지금까지 모은 소스를 기반으로 영상·팟캐스트·PPT·마인드맵·보고서 등 다양한 결과물을 만들 수 있습니다. 버튼 하나로 바로 실행되지만, 슬라이드를 만들 땐 버튼을 바로 누르지 말고 오른쪽 화살표로 옵션을 먼저 바꿔보는 걸 추천합니다.

옵션을 바꾸면 같은 자료로도 전혀 다른 톤의 슬라이드가 나옵니다:

원피스풍 칠판 스타일 클레이아트 손글씨 스타일 스케치노트 (추천) … 외 50종
팁 — 원본 영상 고정 댓글에 50종 스타일을 정리한 가이드북 링크가 있습니다. 개인적으로는 스케치노트 스타일을 가장 자주 씁니다.
Bonus · 아직 제한적

노트북 → 쇼츠(Shorts) 영상 자동 생성

이번 업데이트로 노트북 내용을 짧은 쇼츠 영상으로 만드는 기능도 추가됐습니다. 다만 아직 영어권에서만 정식 제공되며, 언어를 영어로 바꾸지 않고 한국어로 실행하면 한글 자막이 깨지는 문제가 있습니다. 완성까지는 약 5분 정도 걸립니다. 한국어 정식 지원은 추후 업데이트를 기다려야 합니다.

07
Quality Control

소스 자동 관리 — 결과물의 차이는 소스에서 갈린다

버튼만 누르면 비슷한 형태의 슬라이드나 보고서, 팟캐스트가 나옵니다. 그렇다면 결과물의 차이는 어디서 갈릴까요? 바로 소스의 질입니다. 얼마나 검증되고 신뢰도 있는 소스를 넣었는지에 따라 결과물의 깊이와 정확도가 완전히 달라집니다.

전에는 부족한 자료를 직접 찾아 추가하고 불필요한 소스를 일일이 지우는 과정이 번거로웠는데, 이제는 채팅창에 요청만 하면 AI가 두 단계로 알아서 정리해줍니다.

1
1단계 · 부족한 부분 자동 검토 + 보충현재 등록된 소스에서 누락된 정보가 있는지 AI가 검토하고, 필요한 자료를 자동으로 검색해 후보로 제시합니다. 가져오기 버튼만 누르면 바로 추가됩니다.
2
2단계 · "깡통 소스" 자동 탐지 + 제거내용이 비어있거나(메뉴만 가득한 페이지 등), 신뢰도가 낮거나, 중복된 소스를 AI가 찾아서 알려줍니다. 확인 후 더보기 → 삭제로 정리하면 됩니다.
실행 전 체크
  1. 이전 대화가 다른 주제라면, 점점점(⋯) 버튼 → 채팅 지우기로 먼저 초기화
  2. 준비된 프롬프트를 채팅창에 붙여넣고 실행
  3. 결과로 나온 "비어있는 소스"를 직접 열어 실제로 콘텐츠가 없는지 확인한 뒤 삭제
  4. 정리가 끝나면 라벨 아이콘 → 재고성에서 전체 소스를 다시 라벨링
실전 예시 — 20개 소스를 검토했더니 2개는 본문 없이 메뉴만 가득한 "깡통 페이지"였고, 2개는 오히려 심도 있는 리포트였습니다. 이 프롬프트를 쓰면 이렇게 살릴 소스와 지울 소스를 빠르게 가려낼 수 있습니다.
Summary

한 문장으로 정리하는 NotebookLM 2.0

소스를 모으고, 정리하고, 대화하고, 결과물을 만드는 네 단계 전부가 이번 업데이트로 더 자동화됐습니다.

01Gemini 최신 모델로 이미지 이해력이 좋아졌고, 소스가 없어도 내장 리서치로 자료를 직접 찾아줍니다.
02라벨과 메모→소스 변환으로, 흩어진 자료와 나눈 대화 모두를 지식으로 계속 쌓아갈 수 있습니다.
03결과물의 질은 결국 소스가 결정합니다 — 소스 자동 관리 기능으로 부족한 자료는 채우고, 부실한 자료는 걸러내세요.
기억할 것 한 줄 — 7가지 기능 모두 무료 버전에서 그대로 사용할 수 있습니다. 안 써봤다면 지금 노트북 하나 만들어서 라벨 기능부터 눌러보세요.
