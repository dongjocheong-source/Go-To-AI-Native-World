Nano Banana —
이미지를 이해하고
함께 편집하는 AI

텍스트 이해와 이미지 생성·편집을 결합한 차세대 AI Image Creation & Editing Model입니다. 단순 이미지 생성을 넘어, 이미지 이해·부분 편집·참조 이미지 활용·캐릭터 일관성 유지에 강점을 가진 멀티모달 이미지 AI입니다.

"이미지를 만드는 AI"에서 "이미지를 이해하고 함께 편집하는 AI"로
Definition

기존 이미지 AI와의 차이

기존 이미지 AI는 프롬프트를 받아 매번 새 이미지를 처음부터 생성합니다. Nano Banana는 텍스트와 이미지를 함께 입력받아 이해 → 의도 파악 → 부분 수정 → 재구성의 과정을 거칩니다.

Core Strength

이미지 이해 기반 편집

일반 이미지 AI가 새로운 이미지 생성에 중심을 둔다면, Nano Banana는 기존 이미지를 유지하면서 원하는 부분만 자연스럽게 재구성합니다.

예시 — "배경을 미래형 사무실로 바꾸고 옷은 정장으로 변경" 이라고 요청하면: 얼굴 유지 · 포즈 유지 · 조명 유지는 그대로, 배경과 의상만 자연스럽게 바뀝니다.

Multi-Image Fusion

여러 이미지를 이해하고 하나의 결과물로 결합합니다.

사진 A(인물) + 사진 B(배경) + 스타일 이미지 C → 인물 유지 + 배경 변경 + 스타일 적용이 하나의 결과물로 합쳐집니다.
Natural Language

자연어 편집 & 텍스트 표현 · World Knowledge
