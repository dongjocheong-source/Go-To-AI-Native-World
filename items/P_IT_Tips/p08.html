비슷해 보이지만,
역할이 다른 세 도구

"npm install인가 npx인가, 아니면 yarn을 써야 하나?" Node.js 생태계에서 자주 헷갈리는 세 도구의 역할과 차이를 정리했습니다.

3가지 정의 실습 비교표
Definition

npm, npx, yarn이란?

npm Node Package Manager
Node.js의 기본 패키지 관리자. 패키지 설치·삭제·버전 관리를 담당
npx Node Package eXecute
패키지를 설치하지 않고 임시로 실행해주는 도구. 일회성 CLI 도구 실행에 유용
yarn Facebook 개발
npm의 대안 패키지 관리자. 초기엔 속도·안정성에서 npm을 앞섰으나, 지금은 npm도 많이 따라잡음
Usage

사용 예시

terminal
# npm: 패키지를 프로젝트에 설치
npm install react

# npx: 설치 없이 create-react-app을 일회성 실행
npx create-react-app my-app

# yarn: npm install과 동일한 역할
yarn add react
npx는 특히 프로젝트 생성기(create-react-app, create-next-app 등)처럼 "한 번만 실행하고 끝"인 도구에 적합합니다. 전역 설치로 디스크를 낭비하지 않습니다.
Comparison

한눈에 비교

도구역할주요 용도
npm패키지 설치·관리프로젝트 의존성 관리
npx패키지 임시 실행일회성 CLI 도구 실행
yarn패키지 설치·관리(대안)npm 대체, 팀 컨벤션에 따라 선택
Conclusion
