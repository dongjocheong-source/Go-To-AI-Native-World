Why Vector DB

AI 시대의 데이터베이스, Vector DB

기존 RDB·NoSQL은 키워드 매칭(LIKE 검색)엔 강하지만 '의미'를 이해하지 못합니다. "배고파"로 검색해서 "맛집 리스트"를 찾으려면, 텍스트를 숫자로 바꾼 벡터(Vector)를 다뤄야 합니다. 이 벡터를 저장하고 가장 유사한 데이터를 빠르게 찾아주는 엔진이 Vector DB이고, 그중 하나가 Qdrant입니다.

What is Qdrant

Qdrant란 무엇인가

벡터 유사도 검색 엔진이자 데이터베이스로, 단순 저장을 넘어 프로덕션 레벨 AI 서비스를 위해 설계되었습니다.

🦀
왜 Rust인가메모리 안전성이 뛰어나 서버가 갑자기 죽는 일이 적고, 가비지 컬렉터가 없어 예측 가능하고 빠른 응답 속도를 보장합니다. 대용량 트래픽에서 Java·Python 기반 DB보다 유리합니다.
🕸️
핵심 알고리즘 HNSW수억 개 벡터를 전수 조사(Brute-force)하는 대신, 계층형 그래프로 연결해 고속도로를 타듯 근사 최근접(Approximate Nearest Neighbor)을 찾습니다. 정확도 99%대에 속도는 수백 배 빠릅니다.
🎯
Payload 필터링"서울에 있는(필터) + 분위기 좋은 카페(벡터 검색)"처럼 조건 필터와 벡터 검색을 인덱스 태워 동시에 빠르게 처리합니다. 현업에서 Qdrant를 선호하는 가장 큰 이유입니다.
Core Concepts

핵심 개념 — Collection, Point, Payload

RDB와 비교하면 이해가 빠릅니다.

Collection ≈ RDB의 Table
벡터 데이터가 모이는 저장소. 생성 시 벡터 크기(Dimension)와 거리 측정 방식(Metric)을 미리 정합니다 (예: 1536차원, 코사인 유사도).
Point ≈ RDB의 Row
하나의 데이터 단위. ID(고유 식별자), Vector(임베딩된 실수 리스트), Payload(메타데이터)로 구성됩니다.
Payload JSON 메타데이터
벡터와 함께 저장되는 JSON (예: title, year, category). 인덱스를 걸 수 있어 조건 필터링이 타 DB 대비 압도적으로 빠릅니다.

[실습 2] Python

Python으로 Qdrant 다루기

텍스트를 벡터로 변환해 저장하고, 필터링 검색까지 수행합니다.

1. 연결 및 모델 로드
from qdrant_client import QdrantClient
from qdrant_client.models import VectorParams, Distance
from sentence_transformers import SentenceTransformer

client = QdrantClient(host="localhost", port=6333)
model = SentenceTransformer("all-MiniLM-L6-v2")  # 384차원 경량 모델
2. 컬렉션 생성 + 데이터 삽입
name = "my_library"
client.recreate_collection(
    collection_name=name,
    vectors_config=VectorParams(size=384, distance=Distance.COSINE),
)

docs = [
    {"text": "파이썬은 데이터 분석에 좋은 언어입니다.", "meta": {"tag": "coding", "year": 2023}},
    {"text": "Qdrant는 Rust로 만든 고성능 벡터 DB입니다.", "meta": {"tag": "db", "year": 2024}},
]

points = [
    {"id": i, "vector": model.encode(d["text"]).tolist(), "payload": d}
    for i, d in enumerate(docs)
]
client.upsert(collection_name=name, points=points)
3. 필터링 검색 (Hybrid Search)
from qdrant_client.models import Filter, FieldCondition, MatchValue

query = model.encode("데이터베이스 추천해줘").tolist()

# "year"가 2024인 것만 필터링
f = Filter(must=[FieldCondition(key="meta.year", match=MatchValue(value=2024))])

results = client.search(collection_name=name, query_vector=query, query_filter=f, limit=1)
print(results[0].payload["text"])
# → "Qdrant는 Rust로 만든 고성능 벡터 DB입니다." (2023년 파이썬 글은 제외됨)
"2024년에 작성된 글 중 DB 관련된 것"처럼 조건(필터)과 의미(벡터)를 동시에 만족하는 검색 — 이게 Qdrant의 진가입니다.
