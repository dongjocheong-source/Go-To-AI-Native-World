MCP / Connector 개요

MCP(Model Context Protocol)는 AI Agent와 외부 도구·데이터를 연결하는 표준 인터페이스입니다. 각 MCP는 핵심 역할이 명확히 나뉘며, 아래 지도로 전체 구성을 한눈에 파악할 수 있습니다.

MCP / Connector Map

주요 MCP를 핵심 역할별로 정리한 지도입니다. 목적에 맞는 MCP를 빠르게 고르는 출발점으로 사용합니다.

Local 설치 / 설정

로컬에서 직접 실행·설치하는 MCP 서버입니다. 주로 npx·Docker로 구동하며, 브라우저 조작·크롤링·추론·DB 조회 등 실행 환경이 필요한 도구가 여기에 속합니다.

Playwright MCP
Browser Automation Action

AI 에이전트가 웹 브라우저를 직접 조작하게 해주는 MCP 서버. Playwright는 Microsoft의 브라우저 자동화 도구이며, MCP가 AI와 이를 연결합니다.

동작 구조
AI/LLM → MCP → Playwright → Chrome/Edge → 웹사이트
  • 웹사이트를 열고 특정 정보 검색, 로그인 후 내부 웹 시스템 탐색
  • 버튼/메뉴 클릭 및 폼 입력, 페이지 텍스트·UI 구조 확인
  • E2E 테스트 수행 및 실패 원인 분석, 반복적 웹 업무 자동화
  • AI Coding Agent가 개발 중인 웹앱을 직접 실행해 확인, 자연어 지시로 브라우저 QA 수행
적합한 상황

클릭·입력·로그인 등 "행동(Action)" 중심 작업. "버튼을 눌러 주문 과정을 테스트해줘" 같은 QA·E2E·Agent browsing에 적합합니다.

Firecrawl MCP
Web Crawling Data

AI Agent가 웹사이트에서 정보를 검색·수집·구조화하도록 Firecrawl을 MCP로 연결한 것. Hosted 연결 방식과 Local npx 실행 방식을 모두 지원합니다.

접근법
AI → Firecrawl MCP → Search / Crawl / Scrape → Markdown·구조화 데이터 → AI 분석
비교 항목Playwright MCPFirecrawl MCP
핵심 목적브라우저 조작웹 데이터 수집
잘하는 것클릭·입력·로그인·UI 테스트크롤링·검색·본문 추출
웹페이지 접근실제 브라우저 중심크롤러/API 중심
여러 페이지 수집상대적으로 비효율적강점
구조화 데이터 추출가능하나 주목적 아님강점
로그인/버튼 조작강점제한적
대표 용도QA · E2E · Agent browserRAG · 리서치 · 데이터 수집
적합한 상황

Playwright는 행동(Action) 중심, Firecrawl은 정보(Data) 중심. "이 사이트 제품 페이지를 수집해 기능 차이를 표로 만들어줘" 같은 작업은 Firecrawl이 훨씬 자연스럽습니다.

Sequential Thinking MCP
Reasoning Reasoning

AI에게 문제를 단계적으로 검토·수정·분기하는 사고용 작업공간을 제공하는 공식 reference MCP 서버. 공식 설명은 "dynamic and reflective problem-solving through thought sequences"입니다.

접근 방식
질문 → AI Agent → Sequential Thinking MCP → Thought1 → Thought2 → Thought3 → Revision? / Branch? → Conclusion

@modelcontextprotocol/server-sequential-thinking
PostgreSQL MCP
Structured Data Database

AI Agent가 PostgreSQL의 Schema와 데이터를 이해하고, 자연어로 조회·분석·관리하게 해주는 MCP 서버. "지난 30일 매출이 가장 많이 증가한 제품 10개를 알려줘" 같은 요청을 처리합니다.

  • AI가 SQL을 직접 실행하는 것이 아니라, MCP Server가 DB와 AI 사이의 통제된 인터페이스 역할을 합니다.
  • Microsoft PostgreSQL MCP는 별도의 global 설치 없이 npx로 실행 가능합니다.
Connector 연동 MCP / Connector · 10개

연동 MCP / Connector 구조

Hosted(Remote) MCP 서버에 연결·인증해서 사용하는 방식입니다. 대개 Settings → Connectors → Add custom connector에서 서버 URL을 등록하고 OAuth/계정 로그인으로 인증합니다.

Google Drive MCP
Google · Remote Files + Knowledge

AI Agent에게 사용자의 Google Drive를 검색·읽기·파일 작업 능력으로 제공하는 MCP. 단순 다운로드를 넘어 Agent의 지식 저장소/업무 Context로 활용하는 것이 진짜 가치입니다.

  • 기업 환경에서 Agentic RAG / Knowledge Assistant / 업무 Agent 구성의 기반으로 활용됩니다.
  • 보안: OAuth 2.0을 사용하며, Agent가 사용자의 기존 Drive 권한·데이터 거버넌스 정책을 상속하도록 설계.
  • 서버를 설치하는 게 아니라 Google의 Remote MCP Server에 연결. Google Cloud Project에서 Drive API·Drive MCP API 활성화 필요.
  • Drive MCP는 파일 저장소 관점의 검색·읽기·생성·복사·다운로드에 초점. 문서를 정교하게 편집하려면 Docs / Sheets / Slides MCP를 별도 연결.
Endpointhttps://drivemcp.googleapis.com/mcp/v1
Claude 연결
Settings → Connectors → Add custom connector → Google Drive Advanced Settings에 OAuth Client ID / Secret 등록
GitHub MCP
GitHub · Remote / Local Development

AI Agent에게 GitHub를 읽고 조작하는 개발 협업 능력을 제공하는 공식 MCP. Repository·Issue·Pull Request·Actions·보안 정보를 자연어로 조회·조작합니다.

  • "이 Repository의 최근 PR 5개를 분석하고 문제가 있는 PR을 알려줘", "로그인 오류 Issue를 만들고 수정 Branch·PR을 만들어줘" 같은 요청 수행.
  • Remote·Local 두 방식 모두 제공.
Remote 방식

GitHub가 직접 서버 운영. 설정이 가장 편하고, OAuth 지원 Client에서는 PAT 없이 GitHub OAuth 인증도 가능.

Local 방식

공식 Docker image로 로컬 직접 실행. PAT를 환경 변수로 전달하는 방식을 공식 문서에서 제공.

Remotehttps://api.githubcopilot.com/mcp/
Local · Docker image
ghcr.io/github/github-mcp-server
Figma MCP
Figma · Remote Design

Figma 디자인과 AI 개발 에이전트를 연결하는 MCP. 디자인 요소·컴포넌트·프로토타입 정보를 읽고 분석하며, 최근에는 Canvas에 직접 생성·수정하는 양방향 workflow까지 지원합니다.

  • Figma는 Remote MCP Server를 권장. VS Code·Cursor·Claude Code·Codex·Windsurf 등에서 사용 가능.
  • 공식 안내는 Figma Plugin 설치 후 MCP 연결·인증을 진행하는 방식을 권장.
Endpointhttps://mcp.figma.com/mcp
Higgsfield MCP
Higgsfield · Hosted Media Gen

AI Agent에게 이미지·영상 제작(Media Generation) 능력을 연결하는 Hosted MCP. Higgsfield AI가 공식 제공합니다.

  • 직접 접근하면 인증이 필요해 401이 나오는 것이 정상. MCP Client에서 Higgsfield 계정으로 OAuth 인증해 사용.
  • 로컬 설치가 아닌 Hosted 방식 — 서버 URL을 Client에 등록하면 됨. 별도 API Key 없이 계정으로 인증.
Endpointhttps://mcp.higgsfield.ai/mcp
연결
Settings → Connectors → Add custom connector → Higgsfield → Connect → 계정 로그인
유의 — MCP를 통한 생성은 Higgsfield 크레딧을 사용합니다. 웹의 Unlimited/무료 혜택이 있어도 MCP 자동 생성에는 적용되지 않고 표준 크레딧이 차감됩니다.
Gamma Connector
Gamma · Hosted Presentation

프레젠테이션·문서를 빠르게 생성하는 콘텐츠 생성 Connector(Presentation·Document·Webpage·Social post). 특히 Presentation에 매우 특화되어 있습니다.

  • Claude의 Connector 설정에서 Gamma를 추가하고 Gamma 계정으로 로그인하면 사용 가능.
  • 예: "AI Agent와 MCP의 발전 방향" 10장짜리 임원 보고용 프레젠테이션 · 16:9 · Professional theme · 각 페이지 적절한 이미지 포함.
Canva Connector
Canva · Hosted Design Suite

디자인 생성·편집·관리를 아우르는 Connector로 Gamma보다 범위가 넓음. 단순 생성보다 기존 디자인 검색 + 생성 + 수정 + Brand/Asset + Export까지 디자인 작업환경 연결에 초점.

  • 생성 예: "이번 분기 Galaxy 마케팅 캠페인용 프레젠테이션을 만들어줘".
  • 편집도 지원 — "이 프레젠테이션을 일본 시장용으로 바꾸고 모든 슬라이드를 일본어로 번역해줘".
Endpointhttps://mcp.canva.com/mcp
Gmail Connector
Google · Remote Email

AI Agent가 이메일을 검색·읽기·정리하고, 초안 작성이나 라벨 관리를 하도록 해주는 MCP.

Endpointhttps://gmailmcp.googleapis.com/mcp/v1
유의 — 공식 MCP Tool 기준으로 create_draft는 있지만 직접 send_email하는 Tool은 없습니다. "AI가 마음대로 바로 발송하는 구조"가 아닙니다.
Google Calendar Connector
Google · Remote Schedule

Gmail보다 Action 범위가 더 적극적. "내 일정을 이해하고 회의를 잡거나 변경하는 Calendar Assistant" 역할을 목적으로 합니다.

  • Gmail + Calendar를 함께 연결하는 것이 핵심 — 각각 쓰는 것보다 훨씬 유용.
  • 여기에 Google Drive까지 연결하면 더 강력해집니다.
Endpointhttps://calendarmcp.googleapis.com/mcp/v1
Notion MCP
Notion · Remote Hosted Knowledge + Workspace

AI Agent에게 Notion Workspace를 지식베이스이자 작업공간으로 제공하는 공식 Hosted MCP. 검색·읽기뿐 아니라 페이지 생성·수정 등 쓰기 작업까지 수행합니다.

  • Knowledge Access + Workspace Action이 결합된 점이 핵심.
  • Drive가 파일 저장소에 대한 AI Access라면, Notion은 AI가 읽고 작업하는 Knowledge Workspace에 가깝습니다.
  • 현재 권장 방식은 Remote Hosted MCP.
Endpointhttps://mcp.notion.com/mcp
Slack MCP
Slack · Official Communication

사용자 권한 범위 안에서 Slack의 메시지·채널·파일·사용자 정보를 검색·읽고, 메시지 전송·채널/Canvas 관리 같은 Action까지 수행하는 공식 MCP.

  • 예: "지난 2주간 Project Alpha 관련 논의를 찾아 주요 결정사항과 Action Item을 정리해줘".
  • 단순 검색 Connector와 달리 Read + Write가 모두 가능한 점이 특징.
Endpointhttps://mcp.slack.com/mcp
