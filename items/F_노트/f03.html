Embedded Skill 정보

HTML 리포트 Embedded Skill Spotify Green Pill UI 카드 스타일
Prompt
            
[Embedded Skill - 내부 명령어]
. /deep-research : 워크플로, 교차 검증을 통한 결과 제공 
   .. Claude.ai Research는 웹과 연결된 Google Workspace를 자율적으로 반복 검색·분석하여, 인라인 출처가 포함된 폭넓은 심층 리서치 보고서를 생성.
   .. **Claude Code /deep-research**는 여러 서브에이전트가 병렬 조사하고 결과를 교차검증·투표하여 신뢰도가 낮은 주장을 걸러내는 정확성 중심 워크플로우.
   .. 즉, 빠르고 폭넓은 개인/업무 정보 조사 → Claude.ai Research, **팀 공유용으로 철저한 검증이 필요한 조사 → Claude Code /deep-research**가 적합.
. /goal          : 목표만 걸어두고 수단은 claude가 하도록 한다
   .. /goal은 Claude Code의 내장 슬래시 명령으로, 완료 조건을 설정하면 사용자의 추가 프롬프트 없이 Claude가 조건을 충족할 때까지 자율적으로 반복 작업.
   .. 매 턴마다 별도의 빠른 모델이 대화 기록을 바탕으로 목표 달성 여부를 평가하므로, 테스트 통과·컴파일 성공처럼 결과로 검증 가능한 완료 조건을 명확하게 정의하는 것이 핵심.
   .. 대규모 코드 수정·마이그레이션·백로그 처리 등 명확한 종료 상태가 있는 장기 작업에 유용하지만, 오래 실행될수록 비용이 커질 수 있어 짧고 구체적인 완료 기준 설정이 중요.
. /batch         : 토큰 사용량이 많을 수 있다.
   .. /batch는 Claude Code의 대규모 병렬 변경 명령으로, 코드베이스 전체의 작업을 분석해 5~30개의 독립적인 작업 단위로 분해하고 여러 에이전트가 병렬 처리 진행.
   .. 실행 전 작업 계획 승인을 받고, 각 작업을 격리된 Git worktree에서 수행한 뒤 완료 결과를 PR로 만들어 대규모 변경의 안전성과 관리성을 높입니다.
   .. 프레임워크 마이그레이션·대량 리팩터링·반복 코드 변경처럼 넓은 범위의 작업에 적합하며, 최근 변경 파일을 정리하는 /simplify보다 코드베이스 전반의 대규모 변경에 특화되어 있습니다.
. /doctor        : 별도 설치 필요 없음.
   .. /doctor는 Claude Code의 설치·설정 자가진단 명령으로, 런처·설정·권한·MCP 연결·업데이트·컨텍스트 문제 등을 한 번에 점검합니다.
   .. 최신 버전에서는 단순 진단을 넘어 발견된 문제의 수정까지 지원하며, /doctor·/checkup 또는 세션 시작이 안 될 때 claude doctor로 실행할 수 있습니다.
   .. 특히 스킬/플러그인 과다, 비대한 CLAUDE.md, 느린 훅 등 침묵 실패까지 탐지하며, /status가 현재 상태의 스냅샷이라면 /doctor는 문제를 적극적으로 찾아 고치는 종합검진에 가깝습니다.      
· /plan-plus     : 기획/개발 아이디어를 인터뷰 형식을 통해 구체적으로 다듬는 방법의 bkit 스킬
  .. /plan-plus는 아이디어나 개발 요구사항을 인터뷰 방식으로 구체화해 실행 가능한 계획으로 만드는 bkit 스킬이며, /plan은 코딩 전에 계획 수립을 강제하는 읽기 전용 모드입니다.
  .. /plan에서는 파일 탐색·검색은 가능하지만 Edit/Write/Bash 등 변경·실행 도구는 차단되어, 먼저 단계별 계획을 검토·승인한 뒤 실제 구현으로 넘어갑니다.
  .. 또한 Plan Mode는 Haiku 기반 Explore 서브에이전트를 활용해 코드베이스를 사전 탐색하므로, 메인 컨텍스트를 절약하면서 계획의 정확도를 높이는 데 적합합니다.
