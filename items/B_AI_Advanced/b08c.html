CLAUDE.md vs .claude/rules/ vs Skill 완벽 비교 가이드

세 가지 모두 지침을 저장하지만 로드 방식이 다르다. CLAUDE.md는 전체 프로젝트에, .claude/rules/는 파일 경로 단위로, Skill은 호출될 때만 로드된다.

Overview

핵심 정의

세 가지 모두 지침을 저장하지만, 범위(scope)와 로드 시점이 다르다 — 전역이냐 경로 기반이냐 온디맨드냐.

CLAUDE.md

전체 프로젝트

모든 세션에 필요한 지침 — 빌드 명령, 테스트 규칙, 프로젝트 아키텍처.

.claude/rules/

경로 기반 범위

모든 세션, 또는 일치하는 파일이 열릴 때 로드되는 언어별·디렉토리별 가이드라인.

Skill

작업별 · 온디맨드

호출되거나 관련이 있을 때 로드되는 배포 체크리스트 등의 콘텐츠.

Deep Dive

CLAUDE.md전역 규칙

모든 세션이 필요로 하는 지침 — 빌드 명령, 테스트 규칙, 프로젝트 아키텍처를 담는다.

1
모든 세션 자동 포함명시적 활성화 없이 항상 로드된다.
2
전역 범위프로젝트 전체에 적용되는 전역 규칙이다.
프로젝트 전체에 적용되는 규칙 모든 세션에서 참고해야 하는 정보 빌드 · 테스트 · 배포 명령 프로젝트 구조 및 아키텍처
Deep Dive

.claude/rules/경로 기반 가이드라인

모든 세션, 또는 일치하는 파일이 열릴 때 언어별 또는 디렉토리별 가이드라인을 제공한다.

1
경로 기반 로드파일을 열면 자동으로 해당 규칙이 로드된다.
2
세분화된 범위언어별·디렉토리별로 구분된 규칙을 따로 관리할 수 있다.
파일 구조 예시
  1. .claude/rules/python.md — Python 파일을 열 때 로드
  2. .claude/rules/javascript.md — JavaScript 파일을 열 때 로드
  3. .claude/rules/tests/rules.md — tests/ 디렉토리 파일을 열 때 로드
언어별로 다른 규칙 디렉토리별로 다른 가이드 특정 파일 타입에 대한 규칙 frontmatter가 있는 규칙
Deep Dive

Skill작업별 온디맨드 콘텐츠

온디맨드로, 호출되거나 관련이 있을 때 로드되는 배포 체크리스트 등의 콘텐츠다.

1
호출 시점에 로드사용자가 명시적으로 요청할 때만 로드된다.
2
작업별 범위특정 기능이나 워크플로우, 도메인에 한정된다.
참조용 콘텐츠 필요 API 문서 배포 체크리스트 워크플로우 자동화
Use Cases

실제 시나리오별 선택

시나리오 01 Python 코딩 표준
.claude/rules/python.md

상황: Python 파일마다 다른 규칙(타입 힌트, docstring 등)이 필요하다.

Python 파일 열 때 자동 로드언어별 규칙 분리파일 경로 기반 로드
# .claude/rules/python.md ## 타입 힌트 — 모든 함수에 필수 def add(a: int, b: int) -> int: # 두 숫자 더하기 return a + b
시나리오 02 테스트 디렉토리 규칙
.claude/rules/tests/rules.md

상황: tests/ 디렉토리의 파일들에만 적용되는 특수 규칙이 필요하다.

디렉토리별 규칙 분리tests/ 파일 열 때만 로드테스트 특화 가이드
# .claude/rules/tests/rules.md ## 테스트명 규칙: test_<function>_<scenario> ## Mocking: 외부 API는 반드시 mock 필수
시나리오 03 프로젝트 전체 규칙
CLAUDE.md

상황: 모든 개발자가 알아야 할 전체 프로젝트 규칙이 필요하다.

전체 프로젝트에 적용모든 세션에 자동 로드핵심 정보 포함
# CLAUDE.md ## 빌드 명령 poetry install / poetry run pytest / poetry run python -m app ## 핵심 규칙: Python 3.10+, PEP 8 준수, 모든 함수에 타입 힌트
시나리오 04 배포 워크플로우
Skill · /deploy

상황: 배포할 때마다 체크리스트 확인이 필요하다.

필요할 때만 호출배포 프로세스 자동화선택적 워크플로우
# /deploy Skill □ 모든 테스트 통과 □ 버전 업데이트 □ CHANGELOG 기록 □ Git 태그 생성 poetry run python -m build && twine upload dist/*

Summary

세 문장으로 정리하는 CLAUDE.md vs Rules vs Skill

01CLAUDE.md는 프로젝트 전체가 항상 알아야 할 핵심 규칙이다.
02.claude/rules/는 같은 "항상 로드"라도 파일 경로 단위로 세분화한 규칙이다.
03Skill은 이 셋 중 유일하게 필요할 때만 불러오는, 작업별 온디맨드 콘텐츠다.
