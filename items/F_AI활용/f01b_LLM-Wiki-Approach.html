Overview

LLM Wiki란?

LLM을 활용한 개인 Wiki 시스템입니다. 문서를 자동으로 분석하고, 지식을 구조화하며, AI와 함께 검색할 수 있습니다. 이 비교에서는 철학이 완전히 다른 3가지 오픈소스 프로젝트를 다룹니다.

Ar9av / obsidian-wiki — 에이전트 기반 kytmanov / obsidian-llm-wiki-local — CLI 도구 기반 domleca / llm-wiki — Obsidian 플러그인 기반

Getting Started

설치 및 실행 방법

Ar9av / obsidian-wiki
# 저장소 클론 후 환경설정
git clone <repo-url>
cp .env.example .env
# .env에 API 키 등 입력 → 이후 에이전트가 스킬 파일을 직접 읽고 실행
kytmanov / obsidian-llm-wiki-local
# pip 또는 uv tool로 설치
pip install obsidian-llm-wiki
# 또는: uv tool install obsidian-llm-wiki

# Ollama 기반으로 CLI 명령어 실행
obsidian-llm-wiki <명령어>
domleca / llm-wiki
# Obsidian 안에서 설치 (가장 쉬움)
1. Obsidian 열기
2. 설정 → 커뮤니티 플러그인
3. "llm-wiki" 검색 후 설치
# 이후 파일 저장 시 자동으로 백그라운드 재인덱싱

Use Cases

사용 사례별 추천

사용 사례 1 Obsidian 기반 개인 Wiki domleca / llm-wiki
Obsidian을 이미 쓰고 있고, 설정 없이 바로 자동화된 지식 정리를 원하는 경우.
Obsidian과 완전 통합가장 쉬운 사용성최고 수준 자동화활발한 커뮤니티
1. Obsidian 플러그인 설치 2. LLM 백엔드 선택 3. 파일 저장 → 자동 처리
사용 사례 2 AI 에이전트 기반 시스템 Ar9av / obsidian-wiki
Claude Code 같은 코딩 에이전트를 이미 활용 중이고, 강력한 자동화·확장성을 원하는 경우.
에이전트 중심 설계Claude Code 완벽 통합확장성 높음미래 지향적
1. 에이전트 설정 (Claude Code 등) 2. .env 파일 구성 3. 에이전트가 자동 처리
사용 사례 3 완전 로컬, 오픈소스 중심 kytmanov / obsidian-llm-wiki-local
개인정보 보호가 최우선이고, 클라우드 API를 전혀 쓰고 싶지 않은 경우.
100% 오픈소스클라우드 불필요API 비용 없음완전 로컬 실행
1. pip install 2. Ollama 설치 3. CLI 명령어 실행
