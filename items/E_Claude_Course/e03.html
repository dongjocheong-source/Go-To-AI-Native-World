01 · Overview

Claude Cowork란 무엇인가

Cowork는 데스크톱 앱 안에서 Claude가 사용자와 나란히 작업을 수행하는 모드입니다. 컴퓨터의 폴더를 지정하고, 업무가 있는 앱(Gmail·Slack·Google Drive·캘린더)을 연결한 뒤 원하는 결과를 설명하면, Claude가 계획을 세우고 단계를 밟아가며 실제 결과물을 폴더에 저장합니다.

구분 Chat Cowork Code
핵심 동사 Claude와 생각하기 Claude에게 위임하기 Claude와 소프트웨어 만들기
적합한 작업 문제 사고·초안·브레인스토밍 여러 도구를 넘나드는 다단계 작업 코드베이스 개발
결과물 대화 속 답변 폴더에 저장되는 실제 산출물 커밋되는 코드
핵심 멘탈 모델 — Cowork는 대화가 아니라 위임입니다. 여러 도구를 거치고, 시간이 걸리며, 실제 산출물로 끝나는 일 — 그 전체 흐름을 처음부터 끝까지 처리하도록 설계되었습니다. 그럼에도 사용자는 계속 통제권을 쥡니다: Claude는 시작 전 계획을 보여주고, 발송·삭제·공유처럼 중요한 행동 전에는 기본적으로 먼저 묻습니다.
02 · Setup

설정하기

Cowork는 Mac·Windows용 데스크톱 앱에서 실행하거나, 웹·모바일 앱을 통해 클라우드(베타)에서 실행할 수 있습니다.

앱 설치
claude.com/download에서 데스크톱 앱을 설치하고 로그인한 뒤 Cowork를 선택합니다. 보이지 않으면 유료 플랜이나 최신 버전이 필요할 수 있습니다.
작업 폴더 지정
입력창의 "프로젝트나 폴더에서 작업"을 클릭해 컴퓨터의 폴더를 선택합니다. Claude는 이 폴더 안에서 파일을 읽고 씁니다.
앱 연결 (커넥터)
업무가 있는 곳 — Gmail, Slack, Google Drive, 캘린더 등을 연결해 Claude가 데이터를 읽고 다시 쓸 수 있게 합니다.
Claude가 묻는 것 / 안 묻는 것
어떤 행동을 사전 승인 없이 진행하고, 어떤 행동엔 확인을 구하는지 파악해두면 자신 있게 작업을 맡길 수 있습니다.
참고 — 유료 요금제(Pro·Max·Team·Enterprise)와 데스크톱 앱이 필요합니다. Cowork는 2026년 7월부터 클라우드 베타로도 확장되어, 노트북을 닫아도 계속 실행되는 원격 세션과 모바일 디스패치를 지원합니다.
03 · First Task

첫 작업 처음부터 끝까지 위임하기

질문이 아니라 목표(end goal)를 주는 것이 핵심입니다. 최근 했던 일 중 "생각"보다 "실행"에 가치가 있었던 작업, 여러 도구를 거쳤던 작업, 매주 반복하는 작업을 떠올려보면 좋은 첫 사례가 됩니다.

STEP 01

원하는 결과와 제약을 설명 — 완벽한 문구보다 명확한 목표가 중요
→
STEP 02
명확화 질문 답변
Claude가 필요한 정보를 되물으면 답변 — AskUserQuestion으로 선택지 제시
→
STEP 03
중간 조율(Steer)
계획·진행 상황을 보며 방향을 실시간으로 조정
→
STEP 04
결과물 검토
폴더에 저장된 실제 산출물을 확인하고 마무리
AskUserQuestion — Cowork는 필요하면 사용자에게 되묻는 도구를 갖고 있습니다. 형식·톤·핵심 방향처럼 큰 결정에는 객관식 선택지를, 나머지에는 자유 입력란을 제시해 "빈 화면에 뭘 쓸지 고민하는 것"보다 훨씬 빠르게 방향을 정하게 해줍니다.
04 · Scheduling & Cloud

반복 작업 예약 & 클라우드에서 실행

한 번 검증한 작업은 반복 실행으로 넘길 수 있고, 데스크톱 없이도 웹·모바일에서 작업을 시작하고 확인할 수 있습니다.

Command

/schedule

세션 안에서 /schedule을 입력해 정해진 시간에 프롬프트를 실행하도록 예약합니다. 연결해둔 모든 도구에 그대로 접근합니다.

Always-on

Keep Awake

예약 작업이 시간에 맞춰 실행되도록 컴퓨터를 켜진 상태로 유지하는 옵션. 자리를 비워도 Claude에 계속 접근할 수 있습니다.

Remote

클라우드 · 모바일 디스패치

웹이나 모바일 앱에서 작업을 시작·확인. 휴대폰에서 보낸 요청도 데스크톱의 로컬 파일·연결된 앱·설치된 플러그인에 그대로 접근합니다.

# 세션 안에서 예약 작업 만들기
/schedule 매주 평일 오전 9시에 어제자 Slack #sales 채널을 요약해
  주간보고 스킬로 문서를 만들고 팀 채널에 게시해줘
05 · Standing Context

지침 & 프로젝트로 맥락 고정하기

매번 배경을 다시 설명하지 않도록, Instructions(지침)와 Projects(프로젝트)로 Claude에게 지속되는 맥락을 줍니다.

Instructions
톤·형식·우선 확인할 출처·따라야 할 규칙 등, Claude가 어떻게 작업해야 하는지에 대한 상시 규칙입니다.
Projects
관련 대화·파일을 하나의 지속 맥락으로 묶어, 반복되는 프로젝트에서 매번 참고 문서를 다시 올릴 필요가 없게 합니다.
Connectors 권한
엔터프라이즈 사용자는 관리자가 어떤 커넥터를(Claude in Chrome 포함) 사용할 수 있고, 각각 읽기 전용/쓰기 권한을 가질지 통제합니다.
매주 반복되는 리포트·요약 업무 같은 문서를 계속 참조하는 지속 프로젝트 팀 공통 톤·형식 고정
06 · Skills & Plugins

반복 프로세스를 스킬로, 플러그인으로 묶기

같은 작업을 몇 번 반복했다면, 그 절차를 스킬(Skill)로 저장해 재사용합니다. 여러 스킬·커넥터·명령을 묶으면 플러그인(Plugin)이 되어 팀 전체에 배포할 수 있습니다.

Step 1

Skill 작성

같은 작업을 몇 번 반복한 뒤, 그 절차를 스킬로 기록. 이름으로 직접 호출(/스킬이름)하거나 자연어로 설명해도 Claude가 찾아 씁니다.

Step 2

평가(Evals)로 검증

팀에 공유하기 전, 평가를 통해 스킬이 기대한 대로 동작하는지 확인합니다.

Step 3

Plugin으로 배포

관리자가 조직의 마켓플레이스를 통해 표준 스킬 세트를 역할별로 배포합니다.

일반적인 순서 — 대부분 커넥터·지침으로 시작 → 같은 작업을 몇 번 반복한 뒤 스킬을 작성 → 동료가 "어떻게 설정했냐"고 물으면 그때 공유합니다. 자연스러운 채택 곡선을 따르는 것이 핵심입니다.
07 · Extend

Chrome & Microsoft 365로 확장하기

Cowork는 데스크톱 폴더 밖으로도 뻗어나갑니다 — 브라우저 기반 웹앱과 Office 문서 안까지 직접 들어가 작업합니다.

Browser

Claude in Chrome

웹앱을 직접 조작합니다 — 스크롤, 폼 채우기, 여러 사이트에서 데이터 추출까지. 로컬 폴더로는 닿지 않는 작업에 Cowork를 짝지어줍니다.

Office

Claude for Microsoft 365

Word·Excel·PowerPoint·Outlook 각각의 애드인 안에서 직접 작업 — 문서·스프레드시트·프레젠테이션·메일함을 그 자리에서 다룹니다.

Customize 패널에서 활성화→ 최초 1회 인증→ 모든 세션에서 재사용
08 · Safe Habits

안전하게 공유하는 습관

Claude가 내 계정을 대신해 행동하는 만큼, 권한 모드와 승인 습관을 이해하고 지키는 것이 팀과 안전하게 나눠 쓰는 전제 조건입니다.

🔐 권한 모드

  • 세션·작업 단위로 커넥터 권한 조정 가능
  • 읽기 전용 vs 쓰기 권한을 구분해서 부여

✋ 기본 확인 절차

  • 발송·삭제·공유 등 중요한 행동 전엔 항상 먼저 확인
  • 계획을 먼저 보여주고 승인을 받은 뒤 진행

🤝 팀과 공유하기 전

  • 스킬은 평가(Evals)로 검증 후 공유
  • 조직 승인 없이 회사 컴퓨터에 함부로 배포 금지
유의 — Cowork는 사용자의 로컬 파일과 연결된 계정에 접근합니다. 회사 정책상 승인되지 않은 환경에서 무단으로 다운로드·사용하지 말고, 관리자가 커넥터·권한을 통제하는 조직이라면 그 범위 안에서 작업해야 합니다.
Conclusion

마치며

Cowork는 "내 파일과 앱 안에서 직접 일하는 Claude"입니다. Chat이 사고의 파트너라면, Cowork는 실행의 파트너입니다.

01먼저 작업 폴더와 커넥터를 설정하고, 질문이 아니라 목표를 주는 방식으로 첫 작업을 위임하세요.
02반복되는 일은 예약 작업으로, 지속되는 맥락은 지침·프로젝트로, 자주 쓰는 절차는 스킬·플러그인으로 굳히세요.
03Chrome·Microsoft 365로 범위를 넓히되, 권한과 승인 습관을 지켜 팀과 안전하게 나눠 쓰세요.
