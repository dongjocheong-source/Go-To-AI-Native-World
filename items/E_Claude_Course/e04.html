Agent Loop & Tool Use Skills · MCP Managed Agents
01 · What is the Platform

Claude Platform이란 무엇인가

Claude Platform은 Claude를 프로그래밍 방식으로 빌드하기 위한 Anthropic의 인프라입니다. 브라우저에서 대화하는 대신, 코드에서 구조화된 요청을 보내고 구조화된 응답을 받으며 모델·토큰·툴·시스템 지침까지 모든 디테일을 통제합니다.

🧱 Primitives (기본 요소)

  • Messages API, Tool Use, Files
  • Web Search, Code Execution
  • MCP 서버, Skills

🏗️ Infrastructure (인프라)

  • 매니지드 에이전트, 재시도, 큐
  • Claude 호출이 하나에서 수천 개로 늘어나도 버티는 배관

🎛️ Controls (통제)

  • 대시보드, 평가(Evals)
  • 키·사용량·프롬프트 테스트를 위한 콘솔
핵심 문장 — "기본 요소로 빌드하고, 인프라로 확장하고, 통제로 운영한다." 프롬프트를 잘 쓰는 것과 잘 빌드하는 것은 다른 스킬입니다. 요청 안에 실제로 무엇이 들어있는지, 에이전트가 다음 행동을 어떻게 결정하는지, 비용과 한계가 어디서 발생하는지 알아야 플랫폼에서 가치를 뽑아낼 수 있습니다.
02 · Section 1 · 3 Lessons

첫 API 호출 & 올바른 모델 선택

제로에서 동작하는 호출까지 도달하는 3개 레슨입니다.

Lesson 01

What is the Claude Platform?

무엇을 만들 수 있는지, 어떤 조각들이 있고 어떻게 맞물리는지 전체 그림을 잡습니다.

Lesson 02

Your first API call

요청을 보내고 응답을 제대로 읽는 법을 배웁니다 — 각 필드가 무엇을 의미하고 왜 그렇게 돌아왔는지.

Lesson 03

Choosing the right model

Fable·Opus·Sonnet·Haiku는 각각 비용·지연시간 곡선의 다른 지점에 있습니다. 평판이 아니라 내 예시로 직접 평가해 선택하는 습관을 기릅니다.

비용 관리 — 이 구간에서 Console Workbench, 워크스페이스, 한도(limits) 설정까지 함께 소개합니다. 비용 통제를 나중이 아니라 처음부터 다루는 것이 이 강좌의 특징입니다. 모델 선택은 결국 청구서에서 가장 큰 레버가 됩니다.
03 · Section 2 · 3 Lessons

에이전트는 실제로 어떻게 동작하는가

강좌의 진가가 드러나는 구간입니다. 추상화를 먼저 주는 대신, 루프를 직접 손으로 짜본 뒤에야 SDK의 편의 기능을 소개합니다.

Lesson 04 · Agent Loop
루프를 직접 코드로 작성해봅니다. 대부분의 튜토리얼은 첫 페이지부터 추상화를 쥐여주지만, 이 강좌는 순서를 뒤집어 Tool Runner를 "이해하고 쓰는 편의 기능"으로 만듭니다.
Lesson 05 · What is tool use?
텍스트만 생성할 수 있는 모델이 내 데이터베이스를 조회하고, 내부 API를 호출하고, 파일을 쓰게 만드는 메커니즘. 툴을 정의하고 반환값을 처리하는 법을 다룹니다.
Lesson 06 · What is thinking?
더 어려운 문제를 답하기 전에 추론 과정을 거치는 Extended Thinking. 언제 켜야 유용하고, 언제 그저 불필요한 지연·비용인지 판단하는 법을 다룹니다.
04 · Section 3 · 4 Lessons

내 코드 밖으로 에이전트 확장하기

에이전트를 더 넓은 세계에 연결하는 4개 레슨입니다.

Lesson 07
Built-in Tools

웹 검색·코드 실행·웹 페치처럼 Anthropic 인프라에서 직접 도는 능력. 직접 만들거나 호스팅할 필요 없이 켜기만 하면 됩니다.

Lesson 08
Skills

같은 다단계 작업을 반복한다면, 매번 프롬프트에 다시 설명하는 대신 절차를 한 번 정의해 재사용합니다. 팀·코드베이스 전체에서 일관된 동작을 유지하는 방법.

Lesson 09
MCP

이슈 트래커·데이터베이스·내부 시스템 등, 직접 스키마를 쓰지 않고도 제3자 도구에 Claude를 연결. 텍스트만 다루는 에이전트와 회사의 실제 시스템에서 동작하는 에이전트의 차이를 만듭니다.

Lesson 10
Context Management

데모와 프로덕션을 가르는 레슨. 대부분의 에이전트는 3턴까지는 문제없지만, 10턴 즈음부터 컨텍스트 윈도우가 누적된 툴 출력으로 채워지며 느려지고 비싸집니다. 이를 관리하는 패턴을 다룹니다.

05 · Section 4 · 2 Lessons

루프 실행을 Anthropic에 맡기기 — Managed Agents

직접 루프를 운영할지, Anthropic이 샌드박스에서 관리하는 에이전트를 대신 실행하게 할지를 다루는 2개 레슨입니다.

Lesson 11

What are managed agents?

통제권과 운영 부담 사이의 실질적인 트레이드오프를 다룹니다. 강좌는 어느 한쪽이 정답이라 밀어붙이지 않고, 판단의 문제로 다룹니다.

Lesson 12

Building your first managed agent

Anthropic이 루프를 실행하는 동안 이벤트 스트림을 소비하며 결과를 받아보는 과정을 처음부터 끝까지 만들어봅니다. 실행 환경을 직접 소유하지 않고 에이전트 동작을 원하는 팀에게 가장 빠른 경로입니다.

선택 가이드 — 세밀한 통제와 커스터마이징이 필요하면 직접 루프를, 실행 환경 운영 부담 없이 빠르게 에이전트 동작을 원한다면 매니지드 에이전트를 선택하세요.
06 · Section 5 · 1 Lesson

Claude Code로 API 빌드하기

Claude Code 자체를 이용해 API 연동 코드를 작성하는 독립 레슨으로 강좌를 마무리합니다.

// Claude Code에게 API 연동 코드를 맡기는 흐름
1. "Anthropic Messages API로 스트리밍 챗봇 엔드포인트를 만들어줘"
2. Claude Code가 코드를 탐색·계획·작성
3. 앞선 12개 레슨의 지식으로 결과물을 직접 리뷰
이 순서가 마지막에 오는 이유 — 코딩 에이전트로 연동 코드를 짜는 것은 빠르지만, 결과물을 검토하려면 좋은 코드가 무엇인지 먼저 알아야 합니다. 앞선 12개 레슨이 바로 그 안전장치입니다. Claude Code 101을 이미 들었다면, 두 강좌가 이 지점에서 자연스럽게 이어집니다.
Conclusion

마치며

Claude Platform 101은 지름길보다 메커니즘을 먼저 가르치는 강좌입니다. Tool Runner를 쓰기 전에 에이전트 루프를 직접 짜고, 컨텍스트 관리를 배우기 전에 컨텍스트 윈도우 자체를 이해하고, 규모에서 실제 돈을 쓰기 전에 모델 트레이드오프를 먼저 다룹니다.

02에이전트 루프를 손으로 짜본 뒤 Tool Runner로 축약하고, 내장 툴·Skills·MCP·컨텍스트 관리로 범위를 넓히세요.
03직접 루프를 운영할지 매니지드 에이전트에 맡길지 판단하고, 마지막엔 Claude Code로 빌드하되 결과물은 직접 검토하세요.
