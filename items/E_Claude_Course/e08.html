일은 서브에이전트에게

서브에이전트는 Claude Code가 작업을 위임할 수 있는 전문화된 도우미입니다. 각각 자기만의 대화 컨텍스트 윈도우에서 작동하고, 일을 마친 뒤 요약만 메인 스레드로 돌려줍니다. 복잡한 작업을 병렬 서브에이전트로 분해해 결정론적으로 오케스트레이션하는 법을 4개 레슨으로 정리했습니다.

01 · How Subagents Work

서브에이전트는 어떻게 작동하는가

Claude Code와 대화할 때마다 모든 것이 메인 컨텍스트 윈도우에 쌓입니다. 툴 호출, 파일 읽기, 검색 결과 하나하나가 그 안에 저장되죠. 그 공간은 유한하고, 다 차면 Claude는 대화 앞부분을 놓치기 시작합니다.

STEP 01
위임
메인 스레드가 서브에이전트에게 작업을 맡김
→
STEP 02
별도 컨텍스트
서브에이전트가 자기만의 컨텍스트 윈도우에서 시스템 프롬프트+작업 설명을 받아 작업
→
STEP 03
격리된 탐색
파일 읽기·검색·툴 호출 등 중간 과정은 메인 대화를 어지럽히지 않고 격리됨
→
STEP 04
요약 반환
작업을 마치면 요약만 메인 스레드로 돌아옴
핵심 — 서브에이전트가 받는 것은 두 가지입니다: ① 설정 파일에서 온, 역할과 행동을 정의하는 커스텀 시스템 프롬프트 ② 구체적인 작업 설명(task description). 이 조합이 서브에이전트를 "그냥 또 다른 프롬프트"가 아니라 전문화된 도우미로 만듭니다.
02 · Creating a Subagent

/agents 명령으로 커스텀 서브에이전트 만들기

Claude Code는 내장 서브에이전트(Explore, Plan 등)를 이미 갖고 있지만, 코드 리뷰·테스트 작성·문서 점검처럼 특정 작업에 특화된 나만의 서브에이전트도 만들 수 있습니다. YAML 프론트매터가 있는 마크다운 파일로 정의됩니다.

Step 1

/agents 실행

서브에이전트 관리 메인 인터페이스가 열리고, Create new agent를 선택합니다.

Step 2

범위(scope) 선택

Project-level(현재 프로젝트에서만) 또는 User-level(내 컴퓨터의 모든 프로젝트에서 공유) 중 선택합니다.

Step 3

Claude에게 생성 맡기기

직접 설정을 작성할 수도 있지만, 원하는 동작을 설명만 하면 Claude가 생성하는 방식을 권장합니다.

코드 리뷰 전용 서브에이전트 문서 생성 워크플로우 테스트 작성·검증 전담
03 · Designing Reliable Subagents

신뢰할 수 있는 서브에이전트 설계 패턴

서브에이전트가 유용해지려면, 결과를 메인 스레드가 믿고 바로 쓸 수 있어야 합니다. 세 가지 설계 패턴이 이를 뒷받침합니다.

구조화된 출력 형식
서브에이전트가 자유 서술이 아니라 일관된 형식으로 결과를 반환하도록 지정해, 메인 스레드가 파싱·활용하기 쉽게 만듭니다.
장애물 보고(Obstacle Reporting)
작업을 완수하지 못했을 때도 침묵하지 않고, 무엇이 막았는지 명시적으로 보고하도록 설계합니다.
제한된 툴 접근
서브에이전트가 사용할 수 있는 툴을 필요한 만큼만 제한해, 의도치 않은 행동 범위를 줄입니다.
// 검증 전담 서브에이전트 설정 예시 (개념)
name: verifier
description: 앱을 실행하고 변경 사항이 동작하는지 확인
tools: Bash, Read
// "고치지 말고 보고만 하라"는 지시로 장애물 보고를 강제
04 · When to Use (and When Not)

언제 서브에이전트가 도움이 되는가

서브에이전트는 맥락 관리 문제를 해결하는 도구입니다. 언제 진짜 도움이 되고, 언제 오히려 복잡함만 더하는지 구분하는 것이 마지막 레슨의 핵심입니다.

도움이 되는 경우

위임할 가치가 있을 때
  • 탐색·리서치처럼 결과만 필요한 작업
  • 코드 리뷰처럼 반복적이고 정형화된 작업
  • 메인 대화 컨텍스트를 지키는 것이 중요한 긴 세션

흔한 안티패턴

피해야 할 상황
  • 메인 스레드와 계속 대화가 필요한 작업
  • 과도하게 잘게 쪼개 오버헤드만 큰 위임
  • 출력 형식·툴 제한 없이 무엇이 돌아올지 불확실한 설계
Conclusion

마치며

서브에이전트는 더 긴 Claude Code 세션에서 더 많은 가치를 뽑아내는 가장 실용적인 방법 중 하나입니다. 격리된 도우미에게 일을 맡기고, 필요한 정보만 돌려받으세요.
