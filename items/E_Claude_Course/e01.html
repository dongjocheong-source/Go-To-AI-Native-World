01 · Overview

Claude 기능 이해하기 & 접근 방법

Claude는 글쓰기·분석·코딩·리서치를 아우르는 AI 어시스턴트입니다. 대화형 응답을 넘어 파일을 만들고, 도구를 연결하고, 여러 단계 작업을 스스로 수행할 수 있습니다.

🧠 무엇을 잘하나

  • 긴 문서 요약·작성, 데이터 분석
  • 코드 생성·리뷰, 번역, 브레인스토밍
  • 텍스트·이미지·PDF를 함께 이해

🚪 어디서 쓰나

  • 웹 (claude.ai)
  • 데스크톱 앱 (Windows / Mac)
  • 모바일 앱 (iOS / Android)
  • 개발용 API · Claude Code

💳 요금제

  • Free · Pro · Max · Team · Enterprise
  • Cowork·Code·다중 커넥터 등 에이전트 기능은 대체로 유료 플랜
포인트 — "질문에 답하는 챗봇"에서 시작해, 파일을 다루고 도구를 연결해 실제 업무를 수행하는 업무 에이전트로 확장되는 것이 Claude의 핵심입니다.
02 · Desktop App

Claude 데스크톱 앱 — Chat · Cowork · Code

데스크톱 앱은 상단 3개 탭으로 나뉩니다. 같은 Claude지만 "일하는 자세"가 다릅니다 — 대화, 업무 수행, 개발.

Tab 1

Chat

가장 익숙한 대화형 인터페이스. 질문·작성·요약·브레인스토밍과 웹 검색에 강합니다. 시작점으로 가장 적합.

Tab 2

Cowork

질문이 아닌 목표를 주면 스스로 계획을 세워 수행하는 에이전트. 로컬 파일 읽기/쓰기, 다단계 작업, 반복 작업 예약이 가능.

Tab 3

Code

GUI에 들어온 Claude Code. 프로젝트 단위로 여러 파일을 동시에 다루며 개발 수행. 터미널·VS Code·JetBrains에서도 사용.

구분 Chat Cowork Code
입력 방식 질문·요청 목표(end goal) 제시 개발 작업 지시
파일 접근 업로드 중심 로컬 파일 읽기/쓰기 코드베이스 전체
대상 모두 비개발 지식근로자 개발자·빌더
대표 활용 리서치·초안 문서 정리·리포트 자동화 소프트웨어 개발
선택 가이드 — 브레인스토밍·리서치는 Chat → 파일 기반 업무(문서 정리·리포트 생성)는 Cowork → 소프트웨어 개발은 Code. Cowork는 2026년 7월부터 웹·모바일 베타로도 확장되어, 노트북을 닫아도 계속 실행되는 원격 세션을 지원합니다.
03 · Projects

프로젝트 소개

Projects는 관련 대화·파일·지침을 하나의 지속되는 맥락으로 묶는 작업 공간입니다. 매번 배경을 다시 설명할 필요가 없어집니다.

A
파일 업로드참고 문서를 프로젝트에 상주시켜, 그 안의 모든 대화가 자동으로 참조합니다.
B
커스텀 지침톤·형식·규칙을 프로젝트 전체에 적용해 결과의 일관성을 유지합니다.
C
대화 그룹화같은 주제의 채팅을 한곳에 축적해 히스토리를 쌓습니다. Chat·Cowork가 공통 홈을 공유합니다.
주간보고·리포트 등 반복 업무의 맥락 유지 여러 문서를 반복 참조하는 지속 프로젝트 팀 공통 규칙·템플릿 고정
04 · Artifacts

아티팩트로 만들기

Artifacts는 Claude가 만든 결과물을 대화 옆 별도 창에 띄워 바로 보고, 편집하고, 재사용하게 해줍니다. 코드·문서·시각화가 살아있는 산출물이 됩니다.

Make

무엇을 만드나

HTML/React 앱, 대시보드, 다이어그램, 문서, 차트, 계산기, 게임 등 단일 파일 결과물.

Iterate

바로 수정

"색을 바꿔줘", "탭을 추가해줘"처럼 대화로 반복 개선. 미리보기를 보며 다듬습니다.

Reuse

공유·재사용

완성물은 저장·공유·게시. 데이터가 세션을 넘어 유지되는 인터랙티브 툴도 가능.

실무 예 — 팀 점심 메뉴 투표기, 편집형 회의록 템플릿(PDF/DOCX 내보내기), 검증 현황 대시보드처럼 자체 완결형 HTML 도구를 빠르게 만들어 배포하는 방식이 잘 맞습니다.
05 · Skills

스킬로 작업하기

Skill은 특정 작업을 어떻게 수행할지 담은 지침 폴더입니다. 회사·팀의 방식(형식, 순서, 예외 처리)을 인코딩해 반복 가능한 워크플로우로 만듭니다.

저장된 플레이북
관련 작업이 오면 Claude가 스스로 스킬을 불러 사용합니다.
점진적 로딩
필요할 때 단계적으로 지침을 읽어 효율적으로 동작합니다.
도구와 결합
하나의 스킬이 여러 커넥터/MCP를 조율할 수 있습니다.

Skills = 방법 (How)

무엇을 어떻게

도메인 지식·업무 로직을 담아 신뢰할 수 있는 결과를 만듭니다. "어디를 먼저 보고, 무엇을 확인하고, 어떤 형식으로 낼지"를 정의.

MCP / 커넥터 = 접근 (Access)

어디에 연결

외부 데이터·도구에 연결합니다. 스킬과 합치면 "어디를 보고 어떻게 처리할지"가 모두 갖춰집니다.

실무 예 — 법인 주간보고 처리, SAS 진행 리포트, 티켓 정리, 검증 대시보드 생성처럼 파일-in / 결과물-out 형태의 반복 업무를 스킬로 표준화하면 매번 같은 품질을 얻습니다.
06 · Connectors & MCP

도구 연결하기 — 커넥터 & MCP

MCP(Model Context Protocol)는 Claude를 외부 도구·데이터에 연결하는 개방형 표준입니다. "AI를 위한 USB"처럼, 하나의 방식으로 다양한 서비스에 꽂습니다.

Standard

MCP

Claude가 외부 시스템에 접근하는 공통 규격(배관). 원격 MCP 서버에 직접 연결하거나 직접 서버를 구축.

One-click

Connectors

Anthropic·서드파티가 MCP를 앱 안에 패키징한 것. Google Drive·Slack·GitHub·Notion 등에 로그인만으로 연결.

Bundle

Plugins

스킬 + 커넥터 + 명령을 하나로 묶은 설치형 키트. 팀이 동일한 워크플로우를 한 번에 세팅.

커넥터 켜기→ 로그인 인증→ 대화 중 검색·읽기→ 액션 실행(승인)
사내망 유의 — 데스크톱에서는 액션마다 승인 절차를 둘 수 있습니다. 프록시·보안(PAC) 환경에서는 외부 연결 제한을 먼저 확인해야 합니다.
07 · Research Mode

심층 탐구를 위한 Research 모드

Research 모드는 Claude가 수많은 내부·외부 출처를 스스로 탐색해 하나의 종합 답변으로 정리하는 방식입니다. 단발성 검색을 넘어선 다단계 조사.

STEP 01
계획
질문을 하위 주제로 분해하고 조사 방향을 세움
→
STEP 02
탐색
웹 + 연결된 커넥터의 도구를 자동 호출해 근거 수집
→
STEP 03
교차검증
여러 출처를 비교하며 빈틈을 메움
→
STEP 04
종합
출처가 포함된 구조화된 리포트로 정리
강점 — 커넥터를 통해 사내 자료 + 웹을 함께 조사할 수 있어, 경쟁 분석·기술 조사·시장 리서치처럼 깊이가 필요한 작업에 적합합니다. 조사 중에는 연결된 도구를 별도 승인 없이 호출합니다.

01먼저 Chat으로 익숙해지고, 파일 업무는 Cowork, 개발은 Code로 확장하세요.

03반복 업무는 스킬로 표준화하고, 커넥터/MCP로 데이터에 연결, 깊은 조사는 Research로.
