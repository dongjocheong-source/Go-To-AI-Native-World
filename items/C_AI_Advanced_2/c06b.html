Definition

NLU란 무엇인가?

컴퓨터가 인간의 언어를 단순한 기호 나열이 아니라, 맥락과 의미, 화자의 의도(Intent)까지 총체적으로 파악하게 만드는 AI 분야입니다. 쉽게 말해 기계의 '독해력'이자 '말귀를 알아듣는 능력'입니다.

NLP 가장 큰 개념
기계가 언어를 다루는 모든 기술을 포괄하는 학문 (NLU와 NLG를 모두 포함)
NLU 입력 · 분석
사람 말을 듣고 "무엇을 원하는지" 해석하는 단계 ("배고파" → 음식 주문 의도)
NLG 출력 · 생성
파악된 의미를 바탕으로 자연스러운 문장을 만드는 단계 ("근처 맛집을 찾아드릴까요?")
비유하면 NLU는 '귀와 뇌의 이해 영역', NLG는 '입과 뇌의 말하기 영역'입니다.

LLM 기반 NLU 파이프라인 구축

최근에는 모델을 처음부터 학습시키는 대신, LLM 프롬프트 엔지니어링으로 즉시 강력한 NLU를 구축하는 방식이 대세입니다. 발화에서 의도·개체·감정을 JSON으로 추출해봅니다.

nlu_engine.py
# pip install anthropic
import anthropic, json, os

client = anthropic.Anthropic(api_key=os.getenv("ANTHROPIC_API_KEY"))

def extract_nlu_data(user_utterance):
    # LLM에게 NLU 역할을 부여하는 프롬프트
    prompt = (
        "당신은 최고 수준의 NLU 시스템입니다. 아래 발화를 분석해 "
        "intent(의도), entities(개체), sentiment(감정) 세 항목을 "
        "JSON 형식으로만 응답하세요.\n\n"
        f"발화: \"{user_utterance}\""
    )
    message = client.messages.create(
        model="claude-3-haiku-20240307",  # 빠르고 저렴한 모델
        max_tokens=500, temperature=0.1,  # 일관된 JSON을 위해 창의성 낮춤
        messages=[{"role": "user", "content": prompt}]
    )
    return json.loads(message.content[0].text)

# 테스트: 예약 요청
extract_nlu_data("내일 저녁 7시에 강남역 근처 이탈리안 레스토랑 2명 예약해줘")
# → {"intent": "restaurant_booking",
#     "entities": {"date":"내일","time":"저녁 7시","location":"강남역 근처",
#                   "food_type":"이탈리안 레스토랑","num_people":"2명"},
#     "sentiment": "neutral"}

# 테스트: 불만 접수
extract_nlu_data("어제 시킨 배달 음식이 아직도 안 왔어! 당장 환불해줘!")
# → {"intent": "refund_request",
#     "entities": {"order_time":"어제","issue":"배달 지연"},
#     "sentiment": "negative"}
이 JSON을 바탕으로 식당 예약 API를 호출하거나, 챗봇이 "배달 지연 죄송합니다, 즉시 환불해드리겠습니다"처럼 상황에 맞는 답변(NLG)을 생성할 수 있습니다.

Conclusion

마치며

아무리 화려하게 말하는 챗봇(NLG)을 만들어도, 사용자의 "말의 진짜 의도"를 오해하면 AI 시스템은 쓸모없어집니다. NLU는 모든 AI가 올바르게 작동하기 위한 가장 중요한 첫 단추입니다.

01과거엔 인력을 동원해 규칙을 짜야 했지만, 이제 LLM 덕분에 누구나 강력한 NLU 엔진을 구축할 수 있습니다.
기억할 것 한 줄 — "식당 예약해줘"를 "전화번호 검색"으로 잘못 알아듣지 않도록, NLU는 정확할수록 좋습니다.
